# 研究报告写作规范

适用于本项目的市场扫描、行业研究、财报分析、个股报告及更新说明。读者是愿意认真阅读的投资者；采用正常研报或财经书籍的语言，清楚、准确、有连贯解释，不写成工作流日志、字段清单或口语化科普。

## 先讲清意思，再使用术语

- 每节先写主要判断，再说明原因、证据、限制，以及对投资者意味着什么。段落之间有因果或递进关系，不只是罗列指标。
- 标题写实际讨论的内容，如“利润增长为何没有带来现金流改善”“未来三年的增长主要来自哪里”。不用“现金桥”“价值捕获桥”“终局包”等内部简称，也不在标题后固定加英文流程名。
- 保留有明确行业含义的术语，如毛利率、营运资本、资本开支、自由现金流、折现率。首次出现且影响理解时，就地用一句话解释；不要求读者先看术语表，也不在每次出现时重复解释。
- 内部名称 Pass A、Pass B、Packet、Claim ID 等留在计算说明、数据接口或证据记录中。正文写实际内容，不把内部名称改成另一套生硬的中文简称。
- 不通过大量比喻、反问、“说白了”“你可以理解为”等口头表达降低门槛。能够直接说明产品、客户、收入、成本和资金用途时，直接说明。
- 不把通俗等同于缩短。复杂判断可以充分展开，但每段只发展一个主要观点；段落承担解释，表格承担比较。

## 常见表达怎样改

下表用于提示原意，不作机械词语替换。应根据具体事实重写整句话。

| 内部或生硬表达 | 对投资者的写法 |
|---|---|
| 现金桥、利润到现金的桥 | 利润与现金流为什么不同；扣除经营和投资所需资金后，还能留下多少现金 |
| 价值捕获桥 | 行业增长为什么能带来这家公司的收入和利润增长 |
| 价值泄漏 | 指出利润被什么抵消，例如降价、成本上涨、扩产投入或少数股东权益 |
| 终局、Cn/n | 说明预计哪一年达到怎样的经营规模、届时能产生多少现金，以及此后能否持续 |
| 价格隐含终局 | 按当前股价，公司未来需要实现怎样的收入、利润和现金流 |
| Narrative Gap | 我们的判断与市场预期有何不同；独立估值与当前价格相差多少。两者不可混为同一概念 |
| 证伪条件 | 什么事实会使这一判断不再成立；达到何种情况需要下调预期 |
| 冻结基线 | 上次报告采用的假设与判断，注明日期 |
| 正常化利润 | 剔除哪些一次性或不可持续因素后，估计可持续的利润是多少 |
| 龙头/确定性载体 | 公司竞争优势有哪些依据，盈利能否持续 |
| 高弹性载体 | 哪项经营变化会让利润增长更快，恶化时损失又会怎样放大 |
| 行业 Beta / 公司 Alpha | 变化来自行业整体改善，还是公司自身竞争力提升 |
| 单位经济 | 明确一件产品、一个客户或一笔业务的收入、成本、利润与资金投入 |
| 估值基础路由、Packet | 估值采用什么财务基础；供估值使用的行业或财务资料 |

## 通俗表达不能改变财务含义

- 净利润、经营现金流、自由现金流、可分配给普通股东的现金和实际分红不是一回事。具体计算仍使用定义准确的名称，不全部改成“赚到的钱”。
- 解释利润与现金流差异时，分清销售是否收款、库存和应收占款、折旧等非现金项目、设备投资、借还款及少数股东。不能简单说“净利润减资本开支就是股东现金”。
- “正常化”不默认等于扣非；剔除什么、为什么剔除、哪些项目仍可能反复发生，都要说明。
- 未来价值、今天折现后的合理价值、当前交易市值分开，明确年份、币种、单位与股数。模型假设不是公司承诺，也不是确定将发生的事实。
- 公司指引、券商预测、研究者判断和已披露事实用自然语言明确归属。不要为了行文顺畅隐去重大不确定性。

## 数字、表格和结论

- 数字后解释原因与意义。例如收入增长是否来自销量、涨价或收购，利润增长能否持续，是否需要更多资金支持。
- 主报告只保留影响结论的比较表。很宽的表拆为“经营变化”“估值比较”“后续跟踪”等有明确目的的小表；不要强迫读者横向阅读十几个字段。
- 正文优先使用“悲观、基准、乐观情景”“未来稳定经营阶段”，不默认展示 C0/Cn/n/r。需要推导时给出中文定义和单位，再放公式或计算附录。
- 不只给“值得购买”或“估值偏高”的标签。说明当前价格、合理价值、适用期限、主要依据、最大风险，以及什么新事实会改变判断。
- 引用紧邻重要事实或集中列主要来源，做到可追溯但不打断阅读；内部检索日志、置信度字段和完整证据表按需另附。

## 写法示例

以下仅演示表达，不是对任何公司的研究结论。

不采用：“现金桥承压，营运资本吞噬利润，终局兑现尚待验证。”

可写：“利润增长尚未带来相应的经营现金流改善。需要进一步检查应收账款和存货的变化，判断资金占用增加是业务扩张造成的暂时现象，还是回款和库存管理出现问题。如果后续销售能够收回现金，当前差异可能缩小；若账期继续延长，就需要下调对未来可分配现金的估计。”

不采用：“公司是高弹性载体，价值捕获仍受供给响应制约。”

可写：“如果销量增加而固定成本变化不大，公司利润可能比收入增长更快。但这一判断还取决于竞争对手的扩产速度；若新增供给迫使公司降价，销量增长带来的利润改善可能被抵消。”

## 交付前阅读检查

逐段检查读者能否知道“发生了什么、为什么、对判断有什么影响”；将只点术语却没有解释的句子重写。核对所有简化表述没有改变会计定义、估值条件或证据强弱。技能中保留的英文接口名及计算变量不必翻译，但不得因模板复用自动进入正文。
