# 个股研究完整流程契约（Stock Research Process Contract）

> 投资者制定（2026-08-24 纳入 AGENTS.md）。本文件是 AGENTS.md「个股研究完整流程（9 阶段）」的完整执行契约。所有个股研究必须逐阶段推进，不允许直接跳到估值或股价结论。

---

## 一、研究任务启动（Task Initiation）

先明确并记录：

- 公司名称和股票代码（**先经 Tushare `stock_basic` 确认代码**，避免把简称、子公司或概念误认为上市公司）；
- A股 或 港股；
- 截止日期（As-of Date）；
- 投资者真正想解决的问题；
- 当前是否持有、成本和仓位（未知则如实标记 Unknown，不虚构）；
- 是否需要与其他候选公司比较（无候选集则标记"机会排序：未评估"）。
- 输出类型：阶段备忘录或完整 Investment Memo；阶段备忘录必须列出已完成和未完成阶段。

建立研究上下文：

```text
研究对象：
市场：
截止日期：
投资问题：
已有仓位：
已有投资逻辑：
数据缺口：
输出类型：
已完成阶段：
未完成阶段：
```

## 核心机会主线（现有阶段的综合验收）

完整个股研究最终必须回答：该公司是否属于当下结构性产业变化中，景气正在兑现、位于核心利润池、具备可持续公司 Alpha、市场开始认可但尚未充分定价的机会。

这不是新增阶段或闸门。最终由现有 9 阶段共同提供：

```text
时代与现实变化
→ 行业景气及加速度
→ 核心利润池节点
→ 公司 Alpha 与持续性
→ 盈利预期差
→ 市场认可
→ 定价充分程度
→ 为什么是现在
→ 投资状态
```

完整报告开头输出`核心机会判定：符合 / 需要复核 / 不符合`，并说明最先卡住或失败的环节。没有同口径候选比较时必须写`机会排序：未评估`。

市场认可与定价充分程度分开：盈利预期、叙事、资金和趋势用于判断认可；反向隐含预期与情景比较用于判断是否充分定价。跌幅、低 PE/PB、PEG、券商目标价或主题热度均不能单独完成这两个判断。

阶段5—7必须共用一份带日期的`预期位置记录`：按短期、中期、长期保存市场基线、Agent 差异、事件前预期、实际结果、预期修正方向、价格量能反应、价格隐含假设、下一验证和证伪条件。可用“旧预期消化 / 新预期形成 / 事件或业绩验证与预期修正 / 广泛扩散与充分定价检查”描述当前位置，但该标签不是新增阶段或闸门，也不能只凭股价、成交量或事后叙事判定；不同期限可以处于不同位置。“广泛扩散”只触发隐含预期复核，不自动等于“出货”，除非有直接的持仓、换手、供给或卖出证据。

## 二、完整研究链（9 阶段 → Skill 路由）

| 阶段 | 核心问题 | 主要输出 | 调用 Skill | 研究闸门 |
|---|---|---|---|---|
| 1. 市场环境 | 当前市场是否支持风险暴露？ | 市场状态、风险约束、流动性环境 | `investment-market-opportunity-scanner`（Regime 部分） | 通过 / 需要复核 |
| 2. 产业趋势 | 未来 3-5 年产业价值是否变化？ | 产业趋势、周期位置、核心驱动 | `investment-industry-value-chain` | 通过 / 需要复核 / 不通过 |
| 3. 利润池 | 价值最终流向产业链哪个环节？ | 价值链、利润池位置、竞争格局 | `investment-industry-value-chain` | 通过 / 需要复核 / 不通过 |
| 4. 公司Alpha | 为什么利润会流向这家公司？ | 商业模式、竞争优势、竞争比较、优势持续性 | `investment-company-alpha` | 通过 / 需要复核 / 不通过 |
| 5. 盈利与预期差 | 市场预期是什么？Agent 与市场哪里不同？ | 盈利判断、市场观点、预期位置、预期差来源 | `investment-earnings-valuation` | 通过 / 需要复核 / 不通过 |
| 6. 估值与流动性 | 当前价格隐含了什么未来假设？赔率是否合适？ | 情景估值、隐含预期、流动性、风险收益比 | `investment-earnings-valuation` | 通过 / 需要复核 / 不通过 |
| 7. 催化与趋势 | 为什么是现在？市场是否开始重新定价？ | 催化剂优先级、趋势确认、买入条件 | `investment-timing-portfolio` | 通过 / 需要复核 / 不通过 |
| 8. 组合与仓位 | 这项投资放入组合后是否合适？ | 投资状态、加减仓条件、卖出逻辑 | `investment-timing-portfolio` | 观察 / 试仓评估 / 买入评估 / 持有 / 减仓 / 卖出 |
| 9. 投资逻辑跟踪 | 原始假设是否被事实验证？ | 逻辑变化、指标跟踪、重新运行触发条件 | `investment-thesis-monitor` | 强化 / 未变 / 减弱 / 失效 |

> 第 7、8 阶段属于 `investment-timing-portfolio`，不是额外增加独立 Skill。
>
> `investment-financial-statement-analysis` 是财报辅助证据 Skill，不新增阶段或闸门。完整研究中，它在阶段5内部生成 `Financial Statement Evidence Packet`，交由 `investment-earnings-valuation` 完成盈利预期差与估值判断；单独看财报时只输出《财报分析报告》，不得形成完整投资状态。

## 三、每阶段必须使用的同一推理链

禁止从"行业很热门"直接跳到"公司可以买"。逐层推导：

```text
事实
↓
发生了什么变化
↓
对商业有什么影响
↓
对收入、利润和现金流有什么影响
↓
市场当前如何定价
↓
是否存在预期差
↓
投资决策
```

示例：

```text
事实：数据中心功耗持续提升
↓
变化：传统风冷逐渐出现瓶颈
↓
商业影响：液冷渗透率提升
↓
盈利影响：液冷设备厂商订单和价值量增加
↓
市场定价：市场是否已经充分交易液冷成长
↓
结论：如果盈利兑现尚未定价，才形成预期差
```

## 四、研究闸门和停止规则

每阶段给出：**通过 / 需要复核 / 不通过**。

| 情形 | 处理 |
|---|---|
| 产业趋势不成立 | 停止该产业逻辑 |
| 利润池无法流向公司 | 停止该公司研究（可研究产业链其他环节） |
| 公司没有竞争优势 | 停止公司分支 |
| 预期差不存在 | 最多进入观察，不形成积极投资结论 |
| 估值过高 | 否定当前价格，不一定否定公司 |
| 趋势未确认 | 否定当前时点，不一定否定基本面 |
| 组合风险过高 | 不增加风险，必要时减仓或保持观察 |

宽泛行业不能因板块整体表现不好就整体否定，应先拆分细分环节（Recheck—Subsegment）。

## 五、数据源分工

| 数据源 | 用途 | 边界 |
|---|---|---|
| Tushare | 行情、财务、估值、行业表现、业绩预告、流动性 | 结构化事实，优先 |
| 观察者03知识星球 | 市场叙事、机构关注、产业链讨论、催化剂 | 证明"市场观点/研究叙事"，不能单独证明订单/收入/利润/客户事实 |
| IMA【爱分享】 | 财经资讯、研报、行业资料 | 同上 |
| 研报 CLI | 券商报告、盈利预测 | 同上 |
| Web Search | 公司公告、监管文件、政府政策、行业协会、公司官网 | 一手资料交叉验证 |

重要结论必须尽量使用两类以上来源交叉验证。

## 六、最终报告的呈现顺序（14 节，决策优先）

1. 核心机会判定与投资核心叙事；
2. 决策仪表盘；
3. 投资结论；
4. 决策链条；
5. 关键数据证据表；
6. 市场观点 vs Agent观点；
7. 产业周期和利润池；
8. 公司竞争地图；
9. 盈利预测与预期差；
10. 估值、隐含预期和风险收益比；
11. 催化剂、趋势和投资状态；
12. 加仓、减仓和卖出条件；
13. 监控指标和投资逻辑演变；
14. 数据缺口与需要人工判断的事项。

报告中必须明确区分：**事实 / 变化 / 推断 / 关键假设 / 待验证假设 / 决策 / 未知或数据缺口**。

`预期位置记录`放在第6节作为摘要，并在第9节展示事件前基线、预期修正路径与下一次超预期检验，在第11—13节补充价格量能反应、退出观察项和后续变化；不增加第15节。

### 阶段备忘录与完整 Memo

- 阶段备忘录文件名：`<YYYYMMDD>_<公司>_Stage<阶段号>_<阶段名>.md`；开头必须显示阶段边界、未完成环节、最大可支持结论和下一路由。
- 完整报告文件名：`<YYYYMMDD>_<公司>_Memo[_vX.Y].md`；只有完整 9 阶段链可以使用。
- Company Alpha 阶段只能输出 Alpha 闸门，不能输出买入、仓位或完整投资状态。
- 任一决策关键阶段缺失时，核心机会判定不得写`符合`。

## 七、Agent 和人工的边界

**Agent 负责**：数据获取和整理；财务和估值计算；信息归纳；产业链拆解；风险识别；逻辑推演；投资备忘录生成；持续跟踪和触发重新研究。

**投资者判断**：长期产业趋势是否真正成立；管理层和治理质量；非结构化信息的可信度；组合集中度和资金约束；最终是否买入、持有或卖出。

**最终产物不是一句"买入"，而是一条有事实支撑、能够被验证、也明确知道何时会失效的投资逻辑。**
