# Decision and Presentation Contract v2.0

本契约统一投资研究的对外呈现、公共 schema 和 Memo 组装。只在需要形成阶段报告、完整研究、候选比较或逻辑更新时读取；不增加阶段、闸门或评分。

## 核心机会判定卡

完整公司 Memo 以紧凑的`核心机会判定卡`开头：

```text
核心机会判定：符合 / 需要复核 / 不符合
最先卡住或失败的环节：
时代与现实变化：
行业景气及加速度：
核心利润池节点：
公司 Alpha 与具名同行证据：
Alpha 持续性：
市场认可——预期/叙事证据：
市场认可——价格/量能证据：
预期位置——期限/当前阶段/下一验证：
当前价格隐含预期：
尚未充分定价的预期差：
为什么是现在：
当前投资状态：
机会排序：第 X / 未评估
最大数据缺口与下一验证：
```

完整链条充分支持才可写“符合”；决策关键环节未解决写“需要复核”；必要环节失败写“不符合”并标明失败属于行业、利润池、公司Alpha、预期差、当前价格、时点或组合。

阶段 Memo 不使用完整判定卡，改为显著的`阶段边界`：已完成阶段、未完成阶段、最大可支持结论、首个阻断环节和下一路由。

## 决策优先结构

完整 Memo 的阅读顺序：

1. 核心机会判定卡与投资核心叙事；
2. 决策仪表盘；
3. 决策链条；
4. 关键数据证据表；
5. 市场观点 vs Agent；
6. 产业周期与利润池；
7. 公司竞争地图；
8. 盈利驱动树；
9. 情景估值、隐含预期与风险收益；
10. 催化剂、趋势与时点；
11. 组合上下文与投资状态；
12. 加仓、减仓与退出条件；
13. 监控基线、逻辑演变、来源、计算和冲突。

决策仪表盘至少包含：当前状态、一句话逻辑、为什么现在、市场叙事与差异、预期位置、最强证据、主要风险、情景价值/风险、状态变化条件、下一验证日期和组合上下文。

## 投资核心叙事

用简短链条展示：

```text
现实变化 → 产业变化 → 利润池迁移 → 公司获得利润
→ 收入/利润/现金流 → 市场预期 → 预期位置
→ 当前价格隐含预期 → 催化与验证 → 趋势确认 → 投资状态
```

每一环标明事实、变化、推断、假设、待验证假设或决策。该部分是论证地图，不替代证据表。

## 关键证据表

决策关键变量优先使用：

| 变量 | 最新值 | 具名基线 | 变化 | 商业影响 | 盈利/现金流影响 | 来源/日期 | 下一验证 |
|---|---:|---:|---:|---|---|---|---|

“市场预期”必须注明它是明确一致预期、券商预测区间、价格反推假设还是定性叙事。来源冲突并列，不通过平均或模糊措辞消除。

机会发现另附覆盖记录：扫描模式、起止日期、来源覆盖、候选颗粒度、证据等级和未覆盖范围。

## 候选比较

只有多个候选明确在研究范围内时，建立一次工作流级比较：

```text
候选对象
时代与现实变化
行业景气及加速度
行业趋势与利润池
公司 Alpha 与持续性
预期差与盈利可见性
估值和风险收益
催化、时点与趋势
流动性与组合适配
机会成本
相对顺序及决定性原因
未知或数据缺口
```

不得把字段转换成自动评分或买入信号。没有有效候选集时写“机会排序：未评估”。

## 行业机会观点卡

行业扫描或研究在长文前呈现：

```text
核心观点：
为什么现在：
关键数据及基线：
事实到盈利的推导链：
市场当前认知与证据等级：
Agent 潜在不同判断：
利润池预检：
主要风险与证伪：
下一验证：
阶段决策及范围：
```

Radar Only 只能生成研究假设，不能单独支持行业、利润池、盈利、估值或组合 Pass。宽泛行业的弱价格或稀疏讨论不能在未拆分前支持整体 Reject。

完整行业研究在机会观点卡后加入六问卡：

| Q | 覆盖状态 | 核心结论 | 决定性证据/变化 | 对其他问题的约束 | 置信度 | 缺口/下一验证 |
|---|---|---|---|---|---|---|

状态只使用 Supported / Recheck / Not Material 并说明范围；它不是六个新闸门或分数。另列只包含重要相互作用的 Cross-Question Constraint Map。

## 公司竞争地图

```text
公司
具名竞争者
优势来源
经营证据
竞争者反应
结构性或暂时性
为何难以复制

```

公司 Alpha 还要说明优势可能持续多久、侵蚀机制和验证持续性/侵蚀的指标。没有具名同行基线的泛化优点不是Alpha证据。

## 分期限预期

- 短期：未来1—2个季度；
- 中期：未来1—2年；
- 长期：未来3—5年。

各期限分别记录 Market View、Agent View、差异来源、证据、证伪和改变判断的指标。长期叙事不能在未说明期限时覆盖近期盈利或流动性风险。

## 预期位置记录

阶段5—7与监控共用一份带日期的记录。它是追踪层，不是新增阶段、闸门、机会类型、评分或机械价格周期。

| 字段 | 必填内容 |
|---|---|
| 期限与截至日期 | 短期/中期/长期及观察日期 |
| 当前市场基线 | 一致预期、预测区间、价格隐含假设或明确标注的叙事 |
| Agent 差异 | 变量、幅度/区间、时间、因果原因和可能错误点 |
| 描述性位置 | 旧预期消化 / 新预期形成 / 事件或业绩验证与预期修正 / 广泛扩散与充分定价检查 |
| 事件前预期 | 怎样才算高于、符合或低于预期 |
| 实际与修正路径 | 实际结果、预测/叙事修正方向和幅度，以及加速/稳定/见顶/反转 |
| 认可证据 | 预期/叙事与价格/量能分列 |
| 定价充分度 | 价格已经隐含什么（含隐含天花板 m 及 r 情景，按 earnings-valuation 的标准反算），尚未反映的变量是什么 |
| 下一次超预期检验 | 指标、方向/区间、事件窗口和改变判断的结果 |
| 证伪/退出观察 | 最早恶化指标、修正反转、估值耗尽或认可失败 |

不同期限可以处于不同位置。不得只凭价格判定位置；没有事件前基线不得事后称为超预期；广泛扩散只触发定价复核，不自动等于出货。

若研究“好生意但暂时业绩承压”，在阶段4—6增加检查：独立支持的业务质量和Alpha、暂时而非结构性原因、资产负债表与现金流缓冲、改善中的领先指标、价格仍反映旧盈利路径、带日期验证窗口和证伪条件。关键项缺失时返回Recheck。

## 三种产业时钟

行业研究分别呈现：

```text
生命周期：导入 → 成长 → 成熟 → 衰退
发展阶段：技术突破 → 资本投入 → 商业验证 → 利润释放 → 成熟竞争
短周期：库存 / 产能 / 行业价格 / 宏观敏感性
```

说明当前位置、证据、预计转换、验证期限和利润释放可能延迟的原因，不得用一种时钟替代另一种。

## 催化剂与机会排序

催化剂按重要性排序，每项记录事件、影响变量、窗口、证据置信度、上行/下行情形和下一检查日期。不能改变盈利或市场定价的普通事件不称为催化剂。

候选排序只在比较范围和数据充分时进行，保留决定性证据与冲突，不做数值综合评分。

## 组合上下文

投资者未提供持仓、成本、回撤、集中度、流动性需要或因子暴露时，组合上下文写 `Unknown`，不得虚构仓位。未比较其他机会时，机会成本写 `Not Assessed`。

## 逻辑演变记录

监控更新追加：

| 日期 | 原始逻辑/假设 | 预期指标 | 实际结果 | 解释 | 状态变化 | 重跑触发 |
|---|---|---|---|---|---|---|

状态使用强化、未变、减弱或失效，并标明最早受影响的行业、公司、盈利、估值、时点或组合环节。保留旧记录，不用新事实重写历史。

## Memo 类型

- **Stage Memo / 阶段备忘录**：一个或多个必要阶段未完成；标题和文件名标明阶段，只给阶段闸门和最大可支持结论。
- **Complete Investment Memo / 完整投资备忘录**：完整链已完成，或所有必要阶段都有明确Recheck/Reject记录；可呈现研究级投资状态。
- **财报分析报告（辅助证据输出）**：不产生阶段闸门、估值或投资状态。

Company Alpha Pass只允许进入盈利估值，不证明市场认可或价格合适。

## 投资错误与退出观察

完整Memo说明最可能错在哪里、最先失败的阶段、影响、领先指标和应对。区分“逻辑错误”与“逻辑正确但兑现/认可慢于价格预期”。

退出观察至少考虑：领先经营指标恶化、实际低于保存的事件前基线、盈利修正见顶或反转、Base/Bull被充分定价、正面事件未获价格认可、基本面未变但趋势破坏、核心证伪条件触发。它们是重分析触发器，不是自动订单。

## 中文呈现

对投资者的最终报告使用中文状态、证据标签、节名和解释。公司名、代码、产品名、会计科目和来源名保持原意。常用映射：Pass=通过，Recheck=需要复核，Reject=不通过，Observe=观察，Strengthened/Unchanged/Weakened/Invalidated=强化/未变/减弱/失效。
