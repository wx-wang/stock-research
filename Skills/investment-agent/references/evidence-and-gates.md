# Evidence, Gates and Handoff Contract v2.0

本契约是投资 Skill 的共享操作规则。`AGENTS.md` 是最高层投资者宪章；本文件只把其要求转成可执行规则，不增加阶段、闸门、评分或投资流派。

## 使用时机

所有投资决策 Skill 在形成阶段结论前必须读取本文件。财报分析 Skill 只使用证据与数据边界部分，不输出阶段闸门。

## 研究上下文

任务开始先确认：研究对象与市场、截至日期、投资问题、已有逻辑与仓位、有效上游产物、已知缺口。公司任务还要确认代码、主业口径、输出类型、已完成与未完成阶段；机会发现任务还要确认扫描模式、时间窗口、来源覆盖和候选颗粒度。

## 证据标签

- **事实 Fact**：截至研究日可外部确认的信息；记录观察期、发布日期、单位、口径和来源。
- **变化 Change**：相对具名历史、共识、价格隐含预期或原始假设的差异。
- **推断 Inference**：由事实和变化推导的商业含义。
- **关键假设 Assumption**：结论成立所必需但尚未验证的条件。
- **待验证假设 Hypothesis**：带指标、方向和日期的前瞻判断。
- **决策 Decision**：完整因果链支持的阶段或投资状态。
- **未知或数据缺口 Unknown**：可能改变结论的缺失信息。

不得把推断、假设、市场叙事或单一分析师观点写成事实。来源冲突必须并列并说明其决策影响。

## 因果链

所有重要结论沿以下链条推进：

> 事实 → 相对基线的变化 → 商业影响 → 收入/利润/现金流影响 → 市场定价 → 预期差 → 决策

某一环节对当前 Skill 不重要时说明原因；不得用主题热度、价格涨跌或定性故事跳过中间环节。

完整公司研究最终综合为：

> 时代与现实变化 → 行业景气 → 利润池节点 → 公司 Alpha → 盈利预期差 → 市场认可 → 定价充分度 → 为什么是现在 → 投资状态

这是既有阶段的呈现综合，不是新增闸门。

## 核心机会纪律

1. 行业景气必须是需求、订单、价格、库存、开工、资本开支、利润或现金流相对具名基线的变化；板块涨幅、关注度和研报数量只能触发研究。
2. 行业增长不等于所有公司赚钱；必须验证需求变化如何改变供需、价值量、利润池和企业盈利。
3. 行业 Beta 不等于公司 Alpha；Alpha 必须有具名同行和经营证据，证明价值捕获可归因于公司。
4. 市场认可与定价充分是两个结论。预期/叙事证据和价格/量能证据分列；回撤、低 PE/PB、PEG、目标价或热度不能单独证明低估。
5. “最景气”“最优”“核心”等相对表述必须来自同口径候选比较；没有有效候选集时写“机会排序：未评估”。
6. “广泛扩散”只触发隐含预期复核，不等于“出货”；后者需要直接持仓、换手、供给或卖出证据。

## 预期位置纪律

阶段5—7和监控共用带日期、分期限的预期位置记录。事件前保存市场基线、Agent差异、验证区间和证伪条件；事件后只追加实际结果、预期修正和价格反应，绝不事后改写基线。

没有公司指引、明确共识、预测区间或其他可识别的事件前基线时，可以描述财报事实和历史变化，但不得称为“超预期”。单一券商或分析师观点只能标为预测样本或预测区间，不能自动称为一致预期。

完整 schema 见 [Presentation Contract](presentation-contract.md) 的“预期位置记录”。

## 公共阶段记录

每个决策阶段至少返回：

- 核心结论；
- 支持事实；
- Bull Case 与 Bear Case；
- 关键假设；
- 证伪条件；
- 验证指标、预期方向和时间；
- 催化剂与时间窗口；
- 置信度 High / Medium / Low 及理由；
- 阶段决策 Pass / Recheck / Reject；
- 数据缺口；
- 交接包；
- 本阶段支持与不能支持的核心机会字段，以及最先卡住的环节；
- 输出类型、已完成阶段与未完成阶段。

行业相关阶段还要携带 Industry Scope Card、六问覆盖、关键约束、监控基线与精确利润池节点。阶段5—7和监控还要携带预期位置记录。各 Skill 只在此清单上追加自己的专业字段。

置信度衡量“结论是否可靠”，不是看多程度。负面结论可以高置信 Pass。

## 闸门语义

- **Pass 通过**：本阶段独立问题已有足够证据，可以把结论交给下一阶段；不等于看多、买入或最终投资状态。
- **Recheck 需要复核**：方向可能成立，但关键证据缺失、冲突、过期或尚不可观察。必须说明缺什么、为什么重要、何时与如何验证、验证结果怎样改变结论。
- **Reject 不通过**：本阶段因果主张失败或核心假设已被证伪。必须说明否定范围与重新开启条件。

宽泛异质行业先拆成3—5个细分环节。主要利润池尚未覆盖时使用 `Recheck—Subsegment`；合理拆分后仍无有效候选才使用 `Reject—Current Scope`。六问状态是覆盖记录，不是六个新闸门；关键Q1—Q5缺口可能改变行业或利润池结论时，行业总闸门不能通过。

## 停止与重路由

- 行业趋势失败：停止原产业逻辑。
- 利润池失败：停止该环节或公司分支，可转向其他环节。
- 公司 Alpha 失败：停止该公司分支，行业逻辑可以保留。
- 盈利预期差失败：不存在当前主动边际，最多观察。
- 估值失败：否定当前价格，不倒推否定公司。
- 趋势/时点失败：否定当前时点；只有新基本面证据才回溯上游。
- 组合适配失败：不增加风险暴露，不自动改变上游研究结论。

下游不得在没有新证据时提高上游置信度。上游的 Recheck、Reject、Unknown 和低置信度必须保持可见。

## 财报证据包边界

Financial Statement Analyzer 是辅助证据模块，不返回阶段闸门、估值或投资状态。证据包保留报告期、发布日期、币种单位、合并口径、重述状态、比较基线、财务历史、经营驱动、盈利质量、现金流勾稽、指引/预期比较、异常、验证指标和数据缺口。

下游可以复用带日期的证据包，但必须独立完成本阶段问题：Company Alpha 仍需具名同行证据；Earnings & Valuation 仍需市场预期基线和隐含预期；Thesis Monitor 仍负责逻辑状态分类。

## 跨技能信息流

- 市场环境同时流向盈利估值和趋势组合阶段。
- 全部假设、证伪条件、指标和催化剂流向监控。
- 预期位置记录从盈利估值流向趋势组合和监控，原始事件前基线不得覆盖。
- 行业交接保留行业范围、六问状态、关键约束、监控基线、利润池节点和行业到公司的边界。
- 无候选比较时传递“Comparison / Opportunity Ranking: Not Assessed”。
- 每次交接保留来源、日期、基线、定义、冲突、Unknown和下一验证。

## 数据与行动边界

使用当前获授权的数据，不虚构缺失值，不静默以行业均值替代公司数据，不把叙事源当作订单、收入、利润、客户或技术事实。数据缺失必须显式降为 Recheck 或限定结论。

不得执行交易、生成订单、虚构仓位或精确比例。不得用七层推演、数值评分卡、贝叶斯合成或数值化护城河分替代投资者的因果链和闸门。
