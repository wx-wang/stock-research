# 叙事终局估值

先把公司的生意和利润来源讲明白，再把行业变化、公司能力和财务质量翻译为可计算、可证伪的未来经营状态，最后用 DCF 检验当前价格要求什么。不要把它做成故事包装、术语清单、公司质量评分或倍数计算器。

## 开始前

确认上市主体、代码、市场、估值日、证据截止日、总额或每股口径，以及用户真正要判断的问题。

需要完整公司估值时：

- 使用产业研究结果建立行业终局；缺失时补做必要的产业事实，不强制生成另一份完整报告。
- 使用财报和附注建立正常化现金流基准；必要时调用 `investment-financial-statement-analysis`。
- 阅读 [公司生意、核心驱动与预期差](references/company-business-drivers-and-expectations.md)，完成商业模式、真正受益者、公司质量、三大变量、预期差和消息归因。
- 阅读 [数据源路由](references/data-source-routing.md)，默认用 Tushare 取结构化事实，用观察者03和用户指定的 IMA 知识库建立叙事证据账本。
- 阅读 [方法与模型边界](references/methodology.md)。
- 需要成文报告时再阅读 [输出契约](references/output-contract.md)。

## 必须完成的核心工作

1. **讲清公司怎样赚钱**：说明谁使用、谁采购、谁付钱、客户为什么购买、公司怎样收费和确认收入；按合适的业务单位解释销量、价格、单位毛利、固定/变动成本和现金回收。多业务公司拆分主要收入、利润和资本占用，概念业务不冒充价值主体。
2. **识别未来两年的核心变量**：只保留 1–3 个真正决定正常化归母利润和股东现金流的变量，说明当前基线、领先指标、财务传导、预计时滞和证伪条件。后续消息统一归入这些变量；不能改变变量或模型的消息只作背景。
3. **评估公司质量与下限**：消费 `Financial Base Packet`，检查收入质量、利润质量、现金转化、应收与存货、负债、资本开支、ROE/ROIC、资本配置、治理和竞争优势。回答核心故事只兑现一部分时，公司能否依靠现有业务与资产负债表维持经营；不做质量评分。
4. **定义动态行业终局**：确定最小计价单位、当前行业分母、到终局的需求路径和终局后的长期增长，避免把 TAM、渗透率、份额、单价和利润率重复相乘。
5. **证明公司是真正受益者并识别角色**：建立行业变化 → 可服务市场 → 客户采用/采购份额 → 可交付产能 → 销量/份额/价格/产品结构 → 毛利 → 归母利润 → 股东现金流的桥。与具名竞争者比较，并处理客户压价、扩产、费用、营运资本、少数股东和稀释等价值泄漏。分别判断公司是否具备龙头/确定性载体证据和高弹性载体证据；弹性必须拆解到量、价、利用率、利润率、份额或财务杠杆，不能用标签代替因果解释。
6. **建立财务基准**：从正常化归母利润桥接到股东可分配现金流或 FCFE。同时保留正常化利润基准，判断负现金流是扩张投入、营运资本时点还是结构性不能变现。明确维持/增长性资本开支、债务、少数股东、股权激励和完全摊薄股数。
7. **独立推演 Pass A**：在不使用当前价格、市场目标价或价格隐含参数倒填的前提下，冻结 Bear / Base / Bull 的经营状态、`Cn`、`n`、`r`、终局持续期和证伪条件。卖方材料只作线索和校准，不能代替独立因果推演。默认不赋予概率。
8. **建立市场预期与 Pass B**：在独立底稿冻结后，分列公司指引、有日期和样本的卖方预测集、可观察市场叙事与当前价格隐含状态。独立使用完全摊薄股权价值或每股价格反推 `Cn/m`、`n` 或 `r`；不把任何一种基线称为唯一市场共识。若公司相对行业或龙头滞涨，必须解释尚未识别、兑现可信度不足、竞争力较弱、利润弹性被高估或未知负面因素等竞争原因；“没涨”本身不是预期差证据。
9. **最后比较**：使用核心变量的同口径“市场基线—独立判断—价格隐含要求”表，并只比较同口径的利润、现金流、终局倍数、股权价值或每股价值。解释差异来自需求、份额、价格、单位经济、现金转化、持续时间还是折现率。
10. **建立消息与证据更新机制**：新信息先回答影响哪个核心变量、数量级、确认时点、一次性或可复制、是否已在明确基线中，再判断它改变 `C0/E0`、`Cn`、`n`、`r`、终局持续性，还是不改变模型。保留事件前基线；季度波动若只改变兑现速度，应归为 `n`，不得自动上修终局。

所有核心输入和结论在内部按具体主张处理：`来源 → 原子主张 → 主张分类 → 证据角色 → 来源血缘 → 置信度 → 验证/证伪`。至少分开 `Fact`、`Inference / Hypothesis`、`Market Narrative / Expectation` 与 `Valuation View / Model Output`。叙事只能提出问题、建立预期基线或提示风险，不能覆盖行业、公司或财务事实。对关键主张在底稿中标记 `Evidence Confidence：高 / 中 / 低`；依据直接性、原始性、口径完整度、时效性、真正独立的交叉验证及未解决冲突判断，不做数字评分。低置信度证据不能单独进入 Pass A 的决定性假设。

多个来源若追溯到同一公告、数据库、专家、渠道样本或研究报告，只算一条证据链。必须保留 `Original Source → Secondary Source → Repost / Commentary`，并区分独立原始证据数量与同源转载数量。公司数据与行业结论之间还要竞争检验 `行业 Beta / 公司 Alpha / 细分结构变化 / 会计或基数因素`。

## 估值纪律

- 优先使用股东可分配现金流。若当期现金流为负但正常化归母利润为正，且负现金流可由可识别的扩张性投资或营运资本解释，可使用“利润基础解析情景”；但必须另建利润到可分配现金的转化路径、时间和稀释约束。
- 剔除非经常损益、公允价值、不可持续投资收益及少数股东影响后才能建立利润基准。利润估值不能跳过现金兑现；无法证明长期可变现时只做压力测试。
- 终局后持续增长可用 `g`表示，但 `g` 必须由行业增长、公司份额、单位经济、再投资和稀释共同推出，不得直接把行业增速当成公司永续增速，且必须满足 `g < r`。
- 书中几何发育路径与终局零增长永续只是一个解析情景；至少同时检查折现率区间，并在持续性存疑时使用有限平台或衰减情景。
- 不把 `r=10%` 当固定答案，不用同行 PE 直接代替终局推演，不用产业理论空间直接证明低估。
- 不把同一风险同时放入悲观现金流、情景概率和更高折现率中重复惩罚。
- 负现金流、金融、强周期、资源枯竭、重资产或资本结构复杂时，先判断模型是否适用；不能可靠桥接到股东现金流就输出“仅作压力测试”或“模型不适用”。
- 可运行 `scripts/narrative_dcf.py` 计算正向价值、反推终局倍数和 `r/n` 敏感性。所有输入单位必须一致。

## 输出边界

内部底稿将重要内容标记为：`事实 / 变化 / 推断 / 关键假设 / 待验证假设 / 未知或数据缺口`。主报告默认不逐条展示这些标签。

结论只回答当前价格要求的状态低于、接近还是高于独立证据所支持的状态，以及判断如何被证伪。不要输出择时、趋势确认、买入/卖出、仓位或订单；流动性仅作为价格偏离与跳跃风险的辅助说明。

当前版本不根据研究置信度生成仓位，也不建立价格止损或组合规则。用户未明确要求独立讨论执行层时，保持在研究、估值、证据更新和基本面证伪边界内。

## 写作与呈现

- 成品报告要让认真阅读但不熟悉全部行业术语的人能够理解。保持专业、准确和克制，不写成模型字段堆砌或营销式公司故事。
- 正文按读者问题组织：公司怎样赚钱、行业变化为什么能落到它、公司底子如何、三大变量是什么、市场在期待什么、价格要求什么、什么事实会改变判断。Pass A/Pass B 等方法名放在中文标题后的括号或方法说明中。
- 每节先用一两句话给判断，再给证据和计算。表格负责比较，不能代替解释；公式后必须用普通语言说明它对公司意味着什么。
- 首次出现 `C0/Cn/n/r/FCFE/ROIC` 等术语时，用一句中文解释；后文再使用符号。必要术语保留，不为显得专业而增加缩写。
- 避免“赛道长坡厚雪、核心 Alpha、强壁垒、高景气、业绩弹性巨大、逻辑顺”等空泛表达。改写为客户、订单、销量、价格、份额、成本、利润率、资本开支和现金流的具体变化。
- 不靠大量比喻、反问、口语梗或夸张标题提高可读性；用清楚的商业关系、因果链和适量背景解释。
- 正文优先呈现：当前核心判断、3–5个最重要证据、关键产业或公司变化、市场预期与独立判断的核心差异、最大风险以及下一验证指标。必要的终局与价格隐含数字保留，但不展示完整推理流水账。
- `Evidence Type/Tier`、`Confidence`、`Source Lineage`、`Claim ID`、证据链数量、支持/反证明细和逐条分类默认只存在于内部底稿。只有证据质量会实质改变结论时，才用自然语言写明限制。用户明确要求审计时，才生成独立 `Research Notes / Evidence Appendix / Audit Log`。
