# 叙事估值输出契约

写作遵循[研究报告写作规范](../../../研究规则/研究报告写作规范.md)。以下是分析内容的覆盖要求，正文按读者问题组织，不直接照抄内部名称与字段。


成品报告以投资者判断为中心。九部分是内部覆盖框架，不要求逐章展开；默认主报告压缩为清晰的六部分，每节先回答问题，再给必要证据和计算。复杂参数只在影响结论时出现，正文始终说明这些数字对公司的生意意味着什么。

## 默认主报告结构

1. **当前核心判断**：是否值得购买及条件、公司怎样赚钱、当前价格要求什么；按 [投资判断契约](investment-judgment.md)展示今天合理股权价值、未来指定日期的情景价值、情景回报与下行；
2. **最重要的3—5个证据与变化**：只保留真正改变经营、现金流或终局判断的内容；
3. **市场预期与独立判断的核心差异**：分开公司指引、可识别卖方预测、市场叙事和价格隐含状态；
4. **独立终局与价格隐含状态**：用最少的情景和敏感性数字表达，不展开全部底稿；
5. **最大风险或不确定性**：说明哪一项证据不足会改变结论；
6. **下一步最重要的验证指标与数据来源**。

公司业务、行业长期前景、财务基础、公司如何受益，以及独立估值与当前价格的比较仍必须在内部完成；可按复杂度合并进入上述六部分。研究过程可以复杂，最终表达必须简单。

主报告末尾的数据来源只需列出实际使用的主要资料名称、机构/作者、日期和链接或本地文件，并说明其用途。Tushare 参数、检索关键词、命中数、Lineage 和冲突明细留在内部底稿；仅当数据覆盖不足会改变结论时才简洁说明。

## 报告身份

开头简洁列明：公司全称、代码、市场、估值日、证据截止日、币种、总额或每股口径、完全摊薄股数、当前价格与股权价值、研究问题和决定性数据缺口。

## 1. 先说结论：公司靠什么赚钱，当前价格要求什么

让读者在几分钟内看懂：

- 谁给公司付钱，最主要的产品或服务是什么；
- 利润和股东现金主要由哪项业务产生；
- 公司是否能真正承接当前行业变化，最关键的证据和断点是什么；
- 未来两年最重要的 1–3 个变量；
- 公司质量的主要支撑与薄弱处；
- 独立证据支持的经营状态与当前价格要求相比，是更低、接近还是更高；
- 第一证伪点和最大数据缺口。

这一节给结论，不堆模型符号。若必须出现符号，先解释其中文含义。

## 2. 这家公司怎样赚钱，市场又在讲什么

### 生意本身

用自然语言说明使用者、采购决策者、付款者、客户购买理由、收费方式、收入确认和现金回收。选择适合商业模式的最小经济单位，解释销量或业务量靠什么增长、单位毛利如何形成、固定成本如何被吸收，以及毛利率为什么能够维持或变化。

多业务公司先说明各分部的收入、毛利或经营利润贡献和资本占用。收入很小、尚未商业化或不在上市主体内的概念业务单独标出，不混入主要价值来源。

### 三个核心变量

| 核心变量 | 当前值与日期 | 未来两年独立判断 | 领先指标 | 对收入/利润/现金的传导 | 时滞 | 证伪条件 |
|---|---|---|---|---|---|---|

只保留 1–3 个变量。解释为何它们比其他新闻和指标更重要。

### 市场叙事

分开当前主流、次要和悲观叙事，说明每条叙事由什么事件触发、产业事实支持到哪一步、还缺哪一段利润或现金流验证。公司自述、卖方预测、社群观点和价格隐含要求不得混成一个“市场共识”。

## 3. 行业提供了什么机会，又设下什么限制

定义最小计价单位、当前行业分母、未来需求路径、渗透与替代、终局后行业增速、价值链利润分布、供给响应、技术和监管约束。

先说明未来 6–24 个月的行业状态怎样影响公司，再说明它只改变兑现路径，还是也改变长期终局。区分产业可能边界和当前证据支持边界，不用宽泛 TAM 直接证明公司空间。

## 4. 公司底子如何，利润能留下多少现金

先给一句总体判断：财务质量能否支持这套叙事，以及故事只兑现一部分时公司能否维持经营。随后展示：

- 收入质量、客户集中和订单可取消性；
- 毛利率、费用率和利润的可持续来源；
- 应收、合同资产、存货和回款；
- 经营现金流、维持性与增长性资本开支；
- 债务期限、少数股东、担保、商誉和潜在稀释；
- ROE/ROIC 及历史再投资、并购、分红、回购和融资结果；
- 核心叙事部分落空时的资产负债表承受力。

同时展示调整后的可持续归母利润与可供股东使用的现金，并逐项解释差异。首次出现时说明：`E0` 是剔除不可持续项目后的利润基准，`C0` 是扣除维持经营和必要营运资金后真正可供普通股东使用的现金基准。

若使用利润基础，必须解释现金转化率何时、为什么改善；无法证明长期现金兑现时只做压力测试。

## 5. 为什么行业变化能落到这家公司

正文先直接回答“它是真正受益者、部分受益者，还是只有产业标签”，再展示公司受益链：

```text
行业需求或供给变化
→ 公司可服务的细分市场
→ 客户采用、认证或采购份额
→ 可交付产能与利用率
→ 销量、份额、价格和产品结构
→ 毛利与经营利润
→ 营运资本、资本开支、融资和稀释
→ 股东可分配现金
```

与具名竞争者比较客户、产品、成本、份额、产能、认证和现金回报。无可比行业分母时明示“市占率未知”，使用产能份额、项目份额、客户覆盖或订单漏斗作为代理，但不生造精确份额。

重点指出价值在哪一段可能泄漏：客户压价、上游成本、价格战、良率、费用投入、扩产折旧、应收存货、少数股东或股权稀释。

随后给出公司角色判断，但不转换为组合建议：

| 公司角色 | 支持证据 | 相对具名竞争者的差异 | 主要价值泄漏与下行约束 | 仍需验证 |
|---|---|---|---|---|
| 竞争优势与盈利稳定性 | | | | |
| 利润可能加速增长的原因及风险 | | | | |

若相对行业或龙头明显滞涨，单列“滞涨解释竞争”：市场尚未识别、兑现可信度不足、竞争力较弱、利润弹性被高估、未知负面因素。没有经营证据与同口径价格隐含分析时，不得把“没涨”“涨得少”写成补涨机会。

## 6. 悲观、基准和乐观情况下，公司未来能赚多少

明确说明本节没有根据当前市值、目标价或价格隐含参数倒填。用 Bear / Base / Bull 表达可辨认的经营状态，不分配概率。

| 变量 | Bear | Base | Bull | 证据或推导依据 |
|---|---|---|---|---|
| 行业需求与持续增长 | | | | |
| 公司销量/业务量与份额 | | | | |
| 价格与产品结构 | | | | |
| 单位成本与利润率 | | | | |
| 现金转化、再投资与稀释 | | | | |
| 预计稳定经营阶段每年可供股东使用的现金 | | | | |
| 预计达到该经营规模的年份 | | | | |
| 折现率及选择依据 | | | | |
| 此后的增长或衰退假设 | | | | |
| 首项可能推翻判断的事实 | | | | |

首次出现时解释：`Cn` 是终局年份可供股东使用的现金，`n` 是达到该状态所需年数，`r` 是对时间和风险要求的回报率。表后用普通语言各解释一种状态意味着公司需要做到什么。

## 7. 当前股价需要怎样的未来业绩来支撑

### 可观察的预期基线

在 Pass A 冻结后再整理：

| 核心变量 | 公司指引 | 卖方预测集 | 独立判断 | 差异原因 | 下一验证 |
|---|---|---|---|---|---|

卖方预测集写明券商数、报告日期范围、预测年度、指标口径和区间或中位数。单篇研报、历史趋势、社群热度和公司目标不得称为完整市场共识。

### 当前价格隐含状态

固定模型结构后，一次反推一个主变量，把价格隐含的 `Cn/m`、`n` 或 `r` 还原为销量、份额、价格、利润率、现金转化和持续性要求。清楚区分已经实现、已有证据但未完全实现、尚无证据三类条件。

## 8. 我的判断和市场要求差在哪里

先用一段话说明差异主要由哪一个或哪几个核心变量造成，再给同口径比较：

| 核心变量或结果 | 有来源的市场预期 | 本报告基准预测 | 当前价格要求的业绩 | 差异及原因 |
|---|---|---|---|---|

正式 Narrative Gap 只比较同口径的终局现金倍数、股权价值或每股价值。至少展示折现率和到达时间敏感性；持续性存疑时增加有限平台或衰减情景。每张敏感性表后说明真正决定结论的变量，不把表格本身当作结论。

允许的总结：

- 价格隐含条件低于当前独立证据支持状态；
- 价格隐含条件与当前独立证据支持状态大致接近；
- 价格要求高于当前独立证据支持状态；
- 证据不足，无法形成可靠差异判断；
- 模型不适用或只可作压力测试。

上述价格隐含比较完成后，按 [投资判断契约](investment-judgment.md)给出有条件的购买吸引力判断，附合理价值、回报情景、最关键成立条件和第一证伪点。不得把估值折价自动等同于值得购买，不自动生成卖出指令、仓位、技术择时或订单。

## 9. 哪些新信息值得修改模型

围绕上次报告中最重要的 1–3 项经营假设建立内部更新表。面向投资者的正文只需用简表或段落说明“新事实、原判断、是否需要修改及原因、下一次验证”，不照搬下列完整字段：

| 日期与事件 | 已确认事实 | 影响变量 | 事件前基线 | 数量级与财务口径 | 收入/利润/现金时点 | 一次性或可复制 | 是否已在明确预期中 | 对 `C0/Cn/n/r/持续性` 的影响 | 下一验证 |
|---|---|---|---|---|---|---|---|---|---|

订单、技术、客户、扩产或政策消息如果无法确定金额、履约期、利润率、回款、所需投入或对应期间占比，保留为待验证线索。若消息不改变核心变量、兑现时间、持续性或风险，明确写“暂不改变模型”。

内部底稿最后汇总：

- 下一次最可能改变判断的数据和日期；
- 能推翻当前经营叙事的事实；
- 数据源覆盖与冲突；
- Tushare 接口/参数/日期/原始路径；
- 观察者03和 IMA 的搜索词、命中、全文复核及失败；
- 未知或数据缺口；
- 需要投资者判断的事项。

对决定 Pass A、Pass B 和 Narrative Gap 的核心主张建立证据账本。该账本属于内部研究层，默认保存到 `research_data/` 或独立的 `Research Notes / Evidence Appendix / Audit Log`，不附在主报告中：

| Claim ID | 原子主张 | 类别 | 证据角色 | 置信度 | 根来源 / Lineage ID | 独立原始证据数 / 同源转载数 | 支持与冲突 | 依赖假设 | 下一验证 / 证伪 |
|---|---|---|---|---|---|---|---|---|---|

其中：

- 公司已披露事实、管理层预测、卖方预期、社群叙事和估值输出必须拆成不同主张；
- 低置信度主张只能生成问题或待验证假设，不能单独决定 Pass A；
- 同一原始公告被 Tushare、研报、媒体和帖子重复引用，只计一条原始证据链；
- 对由代表公司数据推导的行业或公司受益判断，标明它更可能是行业 Beta、公司 Alpha、细分结构还是口径/基数因素。

主报告不得默认逐条展示 `Evidence Tier/Type`、`Confidence`、`Source Lineage`、内部 Claim 分类、证据评分、独立证据链数量或完整研究过程。只有证据质量会实质改变估值结论时，才写成读者可直接理解的一句话，例如：“订单改善目前主要来自渠道与卖方调研，尚缺正式经营数据确认，因此未上调独立终局。”用户明确要求完整可审计性时，再单独输出附录，不把附录混入正文。

## 归档

保存到：`研究输出/叙事估值/<公司名>/<YYYYMMDD>_<公司>_叙事估值.md`。原始数据和计算中间件放入 `research_data/`，更新时保留旧版本。
