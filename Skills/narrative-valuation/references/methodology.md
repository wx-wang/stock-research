# 方法与模型边界

## 1. 叙事的可计算定义

叙事必须落到一个终局经营状态，而不是一句形容词。推荐从最小计价单位开始：

```text
终端行业需求量
× 公司可持续份额
× 单位收入
× 单位经营利润率
× 股东现金转化率
= 终局股东可分配现金流 Cn
```

这只是通用骨架，应按行业删除重复项。例如 TAM 已经是收入时，不再乘单位价格；单位利润已经包含毛利率和费用率时，不再重复乘利润率。必须写出单位，检查量纲。

终局不是物理最大值。至少区分：

- 产业可能边界：技术或物理上可能达到；
- 当前证据支持状态：竞争、资本和商业现实下可演绎支持；
- 当前价格隐含状态：由价格反推的确定性等价要求。

正式 Narrative Gap 比较后两者。产业可能边界只能用于压力测试。

## 2. 公司经营叙事先于估值模型

正式建模前必须按 [公司生意、核心驱动与预期差](company-business-drivers-and-expectations.md) 讲清公司怎样赚钱、为什么是真正受益者、公司质量能否支撑终局，并冻结未来两年的 1–3 个核心变量。

公司经营变化至少经过两条桥：

```text
业务量 × 单位价格 × 单位利润 = 经营利润
经营利润 - 维持经营与增长所需现金 = 股东可分配现金
```

实际模型按商业模式调整，不重复计算。行业增长、公司收入、归母利润和股东现金是四个不同层次，必须解释中间的份额、价格、产品结构、成本、费用、营运资本、资本开支、少数股东和稀释。

预期差在独立经营底稿冻结后判断。公司指引、卖方预测集、独立判断和价格隐含状态分列；没有明确事件前基线时，不使用“超预期”。新消息只有改变核心变量、财务基准、终局现金、达到时间、折现率或持续性时才修改模型。

## 3. 从利润到股东现金流

优先采用正常化 FCFE 或等效的股东可分配现金流：

```text
归母净利润
+ 非现金费用
- 维持性资本开支
- 增量营运资本
+ 与经营和增长相匹配的净新增债务
- 归属于少数股东的现金流影响
- 其他不能分配给普通股东的项目
= 股东可分配现金流
```

增长性资本开支不能简单全部加回。若终局增长依赖持续投入、融资或股权激励，应在路径现金流和完全摊薄股数中反映。对总额模型使用完全摊薄股权市值；对每股模型使用完全摊薄每股现金流与每股价格。

### 估值基础路由

- **现金流基础**：当正常化 FCFE/可分配现金为正且具有代表性时，作为默认路径。
- **利润基础**：当正常化归母利润为正，但现金流因可识别的扩张性资本开支、营运资本或一次性时点因素为负时，可建立正常化利润 `E0→En`。必须同时建立现金转化率 `k0→kn`，模型中的可分配现金为 `Et×kt`。
- **收入/单位经济基础**：正常化利润仍不可用时，只建立明确的盈亏平衡与融资路径，不使用标准 `m` 解析式。

利润基础的准入条件是：非经常损益已剔除；收入和应收的真实性可核对；折旧、股份支付、资本化研发、少数股东和稀释已处理；可说明现金转化为何会上升、何时上升以及不上升时的价值。否则，利润只是会计中间量，不是可分配给股东的价值。

## 4. 行业增长与公司位置桥

静态“估值天花板”不足以表达一个仍在生长的行业。每个正式情景至少展示：

1. 当前行业规模、统计区域、产品边界、单位和日期；
2. 从当前到第 `n` 年的需求、渗透、替代或单价路径；
3. 第 `n` 年后的长期行业增速 `g_industry`；
4. 公司当前可比口径收入/销量与份额 `s0`；
5. 公司终局份额 `sn`、排名、具名竞争者及份额升降的因果机制；
6. 利润池所在节点、公司能否从“业务份额”转化为“经济利润份额”；
7. 终局公司可分配现金增速 `g_company`的来源。

精确的收入恒等式为：

```text
公司收入_t = 行业需求_t × 公司份额_t × 单位收入_t
公司可分配现金_t = 公司收入_t × 利润率_t × 现金转化率_t
```

若行业规模本身已是收入，不再乘单位收入。若不存在可比的行业分母，必须写“市占率未知”，可补充产能份额、项目份额、客户覆盖或订单漏斗代理指标，但不得伪造精确市占率。

`g_company` 不等于 `g_industry`。公司长期增长还受份额变化、价格/产品结构、利润率、现金转化、再投资回报和每股稀释影响。任何高于经济长期名义增长的永续假设都应作为上限压力测试，不是默认基准。

## 5. 两次隔离推演

### Pass A：独立状态

先冻结行业终端、份额、单位经济、现金转化、`Cn`、`n`、`r`、持续期和证伪条件。记录每项假设的来源与日期。Bear / Base / Bull 是互相可辨认的经营状态，不是假装精确的概率分布。

### Pass B：价格隐含状态

另起底稿，只使用当前价格、财务基准和明确的模型结构反推 `Cn/m`、`n` 或 `r`。一次只反推一个主变量，其余变量必须固定并展示。不同投资者持有不同预期，因此反推值只能解释为该模型下的价格隐含确定性等价状态。

### Compare

比较前检查：

- 总额对总额，或每股对每股；
- 股权现金流对股权价值，企业现金流对企业价值；
- 相同估值日、币种、股数、净债务和终局结构；
- 相同 `n/r` 时比较 `m`，或相同完整模型时比较价值。

差异是待解释的条件差，不是自动收益率或交易信号。

## 6. 解析模型

对当前正常化股东现金流 `C0>0`，设：

- `Cn`：第 `n` 年终局现金流；
- `m=Cn/C0`；
- `q=m^(1/n)`；
- `r`：权益折现率。

若现金流按几何路径发育：

```text
V0 = Σ[t=1..n] C0*q^t/(1+r)^t + TerminalValue_n/(1+r)^n
```

书中的零增长永续假设为：

```text
TerminalValue_n = Cn/r
```

若终局后公司的股东可分配现金仍可持续增长，可用：

```text
TerminalValue_n = Cn×(1+g_company)/(r-g_company),  且 g_company < r
```

该 `g_company` 必须来自上述行业与公司位置桥，且 `Cn` 已扣除维持增长所需再投资。不得把报告期高增长率永续化。

下一年现金流为 `C1=C0*q`，对应动态倍数：

```text
Forward Multiple = V0/C1
```

模型的几何路径、零增长永续和恒定折现率都是假设。它们提供解析透明度，不代表现实必然沿平滑路径兑现。

## 7. 终局持续性的四个版本

- **零增长永续**：终局竞争格局稳定、资本需求可维持且不存在明确寿命上限时，作为基准或上限情景。
- **增长永续**：只在长期行业增长、公司份额与再投资回报都可证明时使用，并显式展示 `g_company`。
- **有限平台**：终局现金流只维持若干年，之后不再计值。适合专利、项目、周期高位或寿命有限资产的保守测试。
- **平台后衰减**：终局维持若干年，随后按固定负增长衰减。适合技术替代或竞争侵蚀明显的业务。

若终局依赖持续再投资，`Cn` 必须是扣除维持该状态所需投入后的现金流，不能一边假设高增长壁垒，一边把相关资本需求忽略。

## 8. 折现率、时间与风险

- 折现率是时间价值和风险补偿，不是把所有不确定性装进一个数字的垃圾桶。
- 离散事件是否发生可用独立情景表达；发生后的系统性风险和时间价值进入 `r`。同一风险不要重复折价。
- 至少给出低、中、高折现率敏感性，并说明区间依据。
- `n` 既影响达到终局前的现金流，也影响终值折现。某些参数下动态倍数对 `n` 不敏感，不代表价值对延迟不敏感。

## 9. 模型不适用信号

出现以下情况且无法建立替代现金流路径时，不输出伪精确公允价值：

- 现金流 `C0<=0`，且既无可靠的正常化利润，也无法建立融资、稀释、现金转化和盈亏平衡路径；
- 银行、保险等资产负债表本身就是经营原料；
- 商品价格和产量周期主导，单一终局不能代表完整周期；
- 资源或项目有明确枯竭/到期日；
- 归母利润与股东现金流长期严重背离；
- 资本结构、少数股东或潜在稀释无法可靠还原。

此时可以输出变量边界、压力测试和价格要求的条件，但必须标记“模型不适用”或“仅作压力测试”。

## 10. 流动性说明

流动性不改变企业未来现金流，但会改变边际价格如何形成。悲观持有人可卖至零仓位；无法做空的非持有人不能继续表达负需求。低流动性通常意味着更少观点参与、更宽价差、更强订单冲击和更大的价格跳跃，但无法单独推出上涨或下跌方向。
