# Narrative Valuation Research Skills

本目录保存项目的研究 Skills 及配套参考资料。运行时总规则以根目录 `AGENTS.md` 为准。

## 当前默认链路

1. `industry-understanding/SKILL.md`：产业边界、未来 6–24 个月状态、价值链利润分布与长期终局；
2. `investment-financial-statement-analysis/SKILL.md`：财务口径、盈利质量与利润到股东现金的桥；
3. `narrative-valuation/SKILL.md`：公司价值捕获、独立终局、价格隐含终局与同口径 Narrative Gap。

```text
产业事实与终局约束
→ 财务基准与现金转化
→ 公司价值捕获
→ 独立终局（Pass A）
→ 价格隐含终局（Pass B）
→ 同口径比较与证伪
```

当前默认链路只输出研究和估值判断，不输出择时、仓位、止盈止损或交易指令。

## 共享证据纪律

三个 Skill 均以具体主张而非整份来源为处理单位：

```text
来源 → 原子主张 → 主张分类 → 证据角色
→ 根来源与独立性 → 主张级置信度 → 验证与证伪
```

核心信息分为 `Fact / Inference-Hypothesis / Market Narrative-Expectation / Valuation View-Model Output`。Evidence Confidence 只使用高、中、低，不做数字评分；同源转载、数据库复刻和重复引用不增加独立证据数量。代表公司的变化在外推行业前必须区分行业 Beta、公司 Alpha、细分结构和口径/基数因素。
