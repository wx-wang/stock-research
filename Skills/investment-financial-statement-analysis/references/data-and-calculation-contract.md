# 财报数据与计算契约

## 1. 数据身份与可比口径

分析前记录：上市主体、股票代码、市场、报告类型、报告期、公告日、币种、单位、合并口径、是否重述、是否包含终止经营或重大并表变化。

比较顺序按问题选择，不机械固定为五年：

1. 本期累计 vs 上年同期累计；
2. 推导单季度 vs 上年同季度；
3. 推导单季度环比，并说明季节性限制；
4. TTM vs 上一完整年度或上一 TTM；
5. 最近五个完整财年；
6. 公司指引、可识别市场预期、具名同行或行业基线。

A股季报和半年报的利润表、现金流量表通常为年初至报告期末累计口径。单季度数需要用相邻累计值相减；资产负债表为时点数。不得把累计数当作单季度数。

若公司重述历史数据，优先使用最新披露的可比口径并保留“已重述”标记。并购、处置、会计政策、币种或合并范围导致不可比时，分别展示报告口径与可比口径；无法重构则标记数据缺口。

## 2. 核心指标

除非公司或行业存在更合适的定义，使用以下基础口径并显式注明分子、分母、是否年化：

- 毛利率 =（营业收入－营业成本）/ 营业收入；
- 净利率 = 净利润 / 营业收入；
- 归母净利率 = 归属于母公司股东的净利润 / 营业收入；
- ROE = 归母净利润 / 平均归母权益；
- ROA = 净利润 / 平均总资产；
- 存货周转率 = 营业成本 / 平均存货；
- 应收账款周转率 = 营业收入 / 平均应收账款；
- 总资产周转率 = 营业收入 / 平均总资产；
- 资产负债率 = 总负债 / 总资产；
- 流动比率 = 流动资产 / 流动负债；
- 速动比率 =（流动资产－存货及其他不易变现项目）/ 流动负债；
- 经营现金流利润比 = 经营活动现金流量净额 / 同口径利润；
- 经营现金流收入比 = 经营活动现金流量净额 / 营业收入；
- 基础自由现金流 = 经营活动现金流量净额－购建固定资产、无形资产和其他长期资产支付的现金。

平均余额通常取期初与期末平均；季报、半年报的收益类指标和周转率如年化，必须展示年化方法。行业季节性显著时，年化值只能作为辅助，不得替代同季比较。

经营现金流利润比必须说明利润口径是净利润、归母净利润还是扣非归母净利润。基础自由现金流还应说明是否包含租赁、收购、处置、资本化研发，以及能否区分维持性和扩张性资本支出。

## 3. 增长计算与特殊情形

- 同比增长 = 本期 / 上年同期－1；
- 环比增长 = 本单季 / 上单季－1；
- CAGR =（期末值 / 期初值）^(1/年数)－1，仅在期初、期末为同号正值且口径可比时使用；
- 起点接近零、由负转正、由正转负或符号多次变化时，不计算 CAGR，改用绝对变化、分段趋势和驱动解释；
- 百分比变化必须与绝对金额、占收入/资产比例和基数效应同时展示。

## 4. 盈利质量核对

至少检查下列勾稽关系和方向：

- 收入增长与应收账款、应收票据、合同资产、合同负债、销售商品收到现金；
- 营业成本与存货、应付账款、采购现金支出；
- 净利润与经营现金流、非现金损益、营运资本变化；
- 归母净利润与少数股东损益；
- 净利润与扣非归母净利润；
- 研发费用与资本化开发支出；
- 利润增长与政府补助、公允价值变动、投资收益、资产处置和减值；
- 资本开支与固定资产、在建工程、产能、折旧和利用率；
- 有息负债、利息支出、货币资金、受限资金与债务到期结构。

单期经营现金流为负不自动等于风险；需要区分季节性、备货、信用扩张、供应链议价、税费支付和扩张投入。正现金流也不自动代表高质量，需要检查应付款拉长、票据、保理、资产出售和一次性回款。

## 5. 异常识别

异常候选可以由以下方式触发，但不得机械定性：

- 同比、环比或相对历史波动显著；
- 增长与收入、利润、现金流或产能不匹配；
- 占收入、资产、权益或利润的比例达到重大性；
- 与具名同行或公司指引明显偏离；
- 会计政策、估计、审计意见、重述或合并范围变化；
- 管理层解释与报表勾稽关系不一致。

每项异常记录：最新值、基线、绝对变化、相对变化、重大性、可能原因、支持与反证、持续性、下一验证指标。`波动超过30%`只能作为扫描线索，不是红色预警结论。

## 6. 行业适用性

先识别商业模式，再选择指标：

- 制造业：订单、销量、价格、产能、利用率、存货结构、资本开支和单位成本；
- 软件/互联网：递延收入或合同负债、续费、客户留存、获客成本、研发资本化、股份支付；
- 零售/消费：同店、渠道库存、预收、促销、门店和季节性；
- 资源周期：产销量、实现价格、现金成本、品位/储量、维持性资本开支；
- 工程/项目制：合同资产、合同负债、履约进度、回款、客户集中和减值；
- 房地产：销售回款、合同负债、存货项目、债务与受限资金，通用存货周转阈值不直接适用；
- 银行、保险、券商：使用行业专属资产质量、资本、利差、准备金和偿付能力指标，不套用制造业存货与流动比率模板。

若通用指标不重要，写明“不重要及原因”，不要为了填表强行计算。

## 7. 数据不足规则

缺少附注、分部、单季度拆分、同行口径、现金流明细或原始公告时，保留数据缺口并说明：缺什么、为什么重要、如何验证、预计何时可验证、结果如何影响现有判断。不得用数据库空值、媒体摘要或行业平均替代公司事实。

## 8. 利润基准与现金转化诊断

不得因单期自由现金流为负就丢弃正常化利润，也不得因会计利润为正就假设它可全额分配。至少建立：

```text
报告归母净利润
- 非经常性损益及不可持续投资/公允价值损益
± 会计政策、并表范围、少数股东和周期性正常化
= 正常化归母利润 E0

E0
+ 与经营相关的非现金费用
- 维持性资本开支
- 正常化增量营运资本
+ 与稳定资本结构一致的净新增债务
- 普通股东不可分配项目
= 正常化股东可分配现金 C0
```

对负 `C0` 拆解：扩张性资本开支、产能爬坡、营运资本时点、季节性、并购/处置、一次性支付、客户信用恶化、库存积压或结构性资本饥渴。只有前几类可由可验证的产能利用、收入、回款和资本开支回落路径解释时，才建议下游使用“利润 + 现金转化”情景。

现金转化路径至少列示：当前正常化转化率 `k0=C0/E0`、终局转化率 `kn`、预计转折年份、驱动指标、所需融资/稀释和失败条件。`k0` 为负时不直接输入标准解析模型；应根据正常化投入结构重建可辩护的路径或仅做压力测试。
