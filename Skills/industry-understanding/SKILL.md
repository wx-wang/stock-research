# 行业认知地图

## 目标与边界

把一个陌生行业讲明白并做成一张可验证、可更新的认知地图：它解决什么问题，客户为什么付钱，产品和资金怎样流动，价值与利润留在哪些环节，现在处于什么状态，最近发生了什么变化，这些变化能否持续并传到利润，长期又会走向哪里。

本 Skill 是认知工具，不是投资决策工具：

- 不输出买入、卖出、估值目标、交易时点或仓位。
- 不把“行业好”推导为“行业里的公司都好”。
- 可以列代表性玩家帮助理解产业地图，但不得形成股票推荐或公司 Alpha 结论。
- 用户询问个股终局、价格隐含预期或公允价值时，将产业事实整理为 `Industry Terminal Packet` 后交给 `narrative-valuation`；不要用本 Skill 直接计算个股价值。

## 使用方式

根据问题深度选择输出：

- **快速了解**：用读者问题组织答案，先说明行业做什么、谁付钱、怎么赚钱，再给出产业地图、当前状态、最近变化和关键未知；六问只作内部覆盖检查，不机械展示全部框架。
- **系统认知**：完整研究产业结构、未来 6–24 个月状态、叙事变化、利润传导、长期终局、国际比较、中国位置和追踪仪表盘。
- **状态更新**：保留原有产业地图，比较最新数据与上次基线，说明需求、供给、价格、库存、利润池和叙事发生了什么变化，以及哪些长期判断需要调整。
- **终局支持**：在系统认知基础上生成可供 `narrative-valuation` 使用的 `Industry Terminal Packet`。

系统认知或方法不确定时，先读 [完整方法契约](references/methodology.md)。系统认知、状态更新或用户询问供需/景气/叙事变化时，必须读 [行业状态、叙事与利润传导](references/state-change-and-narrative.md)。需要估算行业天花板、终局需求路径或公司可及市场时，读 [天花板推导方法](references/ceiling-derivation.md)。需要组织最终报告时，必须读 [输出模板](references/output-template.md)。需要核对原方法章节时，读 [21 章来源索引](references/source-index.md)。

## 必须执行的流程

1. 建立 **Industry Scope Card**：最终产品/服务、替代品边界、技术路径、地理范围、价值链位置、时间截止点、数据口径。
2. 先用普通读者能理解的话回答：行业解决什么问题、客户是谁、谁付钱、收入怎么产生；再画产业地图，不用术语代替解释。
3. 建立双时间尺度：一条看未来 6–24 个月的经营状态与变化，一条看行业成熟后的需求、竞争和利润边界；短期变化必须说明是否会改变长期终局。
4. 建立 **Industry State Card**，至少检查需求、供给/产能、价格/产品结构、库存、成本与利润池、竞争、技术、政策地缘和资本开支。只突出真正改变判断的 1–3 个变量；没有明显变化时明确写“未发现足以改变判断的变化”。
5. 建立 **Narrative Change Card**：市场此前在相信什么，现在叙事发生了什么变化，哪些已被产业事实支持，哪些仍只是预测或关注度。没有事件前基线时，不使用“超预期”。
6. 对关键变化补完利润传导链：终端需求或供给变化 → 订单/销量 → 价格、产品结构和产能利用率 → 利润池 → 典型企业收入、利润和现金流，并写明时滞、再投资和价值泄漏。
7. 先快速扫描六问，再根据主导力量决定深研顺序：资源型从 Q1，技术型从 Q4，监管型从 Q5，结构稳定型从 Q2→Q3 开始。系统认知最终覆盖全部重要六问：
   - Q1 体量、增长、周期与生命周期；
   - Q2 产业地图、价值链关系与利润分布；
   - Q3 商业模式、竞争、护城河机制与资本回报；
   - Q4 技术 S 曲线、路线切换与颠覆风险；
   - Q5 监管、地缘、国际比较与中国位置；
   - Q6 适用估值语言、市场叙事及其数字假设。
8. 区分供应链、企业价值链与产业链：物流路径不能代替经济关系，单企业内部活动不能代替跨企业利润分配。
9. 系统认知输出六问覆盖记录：`已支持 / 需要复核 / 不重要（说明原因）`；快速了解只展示会影响结论的覆盖缺口。
10. 建立可持续更新的行业字典、分频率 dashboard 和主动证伪清单。指标按实际生成频率更新，不强制所有变量周更。

需要支持个股叙事估值时，追加 `Industry Terminal Packet`：当前行业规模及口径、从当前到终局的需求/渗透/替代/单价路径（推导须使用 [天花板推导方法](references/ceiling-derivation.md)，注明所用方法与依据）、终局后长期行业增速、价值链利润分布、公司份额可行区间的产业约束、单位经济与资本强度、终局持续性、证伪条件、关键未知和下一验证数据，并给出**产业可能边界与证据支持边界**两条线（价格隐含边界由下游估值反推，不在行业层计算）。若下游已指定公司，包含该公司当前可比口径业务规模、份额/排名、具名竞争者和可用代理指标；无统一分母时必须写“市占率未知”。它只提供产业边界，不预设公司一定能够捕获该价值。

## 证据纪律

- 所有重要内容标记为：`事实 / 变化 / 推断 / 关键假设 / 待验证假设 / 未知或数据缺口`。
- 时效性事实必须查询最新资料；优先一手资料、行业协会、监管文件、公司公告和结构化数据。
- 财经媒体、卖方研报和管理层陈述可用于识别叙事，但需考虑各自偏差并交叉验证。
- 卖方研报可用于建立行业地图、发现数据入口和识别市场叙事；报告数量或重复讨论只说明关注度，不自动等于一致预期。关键经营数据尽量追溯原始来源。
- 任何市占率、增速、利润率、估值或国产化率都要写明时间、地区、单位和统计口径。
- 不因资料不足补造数字；可能改变行业边界、利润分布或演化判断的缺口必须标记“需要复核”。

## 写作与呈现

- 成品报告面向希望认真理解行业、但不一定熟悉全部术语的读者。保持研究报告的准确和克制，不写成教科书摘录、字段清单或口号集合。
- 先给判断，再给原因和证据。每个主要章节开头先用一两句话回答本节问题，不让读者从长表格中自行猜结论。
- 首次出现专业术语或缩写时，用一句简短中文解释它在本行业中的实际含义；后文再使用简称。必要术语保留，不为显得专业而堆砌术语。
- 一段集中表达一个主要判断。数字必须服务于判断，并紧邻口径、日期和来源；表格用于比较，不能代替因果解释。
- 避免“高景气、强壁垒、空间巨大、国产替代加速”等空泛表达。改写为可观察的订单、价格、库存、份额、成本、认证、资本开支或现金流变化。
- 不靠大量比喻、反问、夸张标题或口语梗降低理解门槛；用清楚的因果关系和适量背景解释提高可读性。
- `事实 / 变化 / 推断 / 关键假设 / 待验证假设 / 未知或数据缺口`只标在重要判断处，避免每句话都贴标签导致阅读割裂。

## 质量检查

交付前确认：

- 行业定义以可替代性为边界，而非照搬指数分类。
- 产业地图包含节点、关系、代表玩家与利润集中度，并补充横向支援、平台和关键技术节点。
- Q3 说明利润为何能够被留存，而不是罗列“壁垒”。
- Q4 同时讨论新技术、替代材料/方案及商业化时间。
- Q5 按细分环节判断，不用“自主可控”概念替代真实客户采用和技术指标。
- Q6 把叙事翻译成可验证数字，并用 Possible / Plausible / Probable 检验；不做个股公允价值。
- 说清行业当前是改善、恶化还是基本不变，依据相对什么基线；区分短期补库存、周期变化和结构变化。
- 关键变化已推演到利润与现金流，并说明传导时滞、竞争分流和所需资本投入。
- 市场叙事、卖方预测和产业事实分开呈现；关注度不冒充共识，股价变化不冒充行业事实。
- 报告开头能让读者在几分钟内理解行业做什么、谁付钱、利润在哪里、当前最重要的变化是什么。
- 结论明确写出已知、未知、分歧和下一步应验证什么。
