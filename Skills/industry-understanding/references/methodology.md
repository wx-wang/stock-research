# 产业认知方法契约

本参考将 Socratopia《写给投资者的产业链阅读法》21 章提炼为可执行的方法。它保留方法结构，不复制章节原文；原书中的数字和案例只用于解释框架，使用时必须核对最新数据。

## 一、先定义研究对象

产业不是相似公司标签，而是提供可替代产品或服务的企业集合。分析前完成 Industry Scope Card：

| 字段 | 必须回答的问题 |
|---|---|
| 最终需求 | 用户购买的到底是什么功能或结果？ |
| 替代品边界 | 涨价后用户会转向什么？直接和间接替代分别是什么？ |
| 技术路径 | 同一需求有哪些不同实现路线？ |
| 地理范围 | 全球、中国或特定区域？生产地和消费地是否不同？ |
| 链上位置 | 研究整条产业链，还是某个具体环节？ |
| 时间与口径 | 截止日期、数量/金额、出货/装机/消费等口径是什么？ |

复合公司或复合行业用三条修正纪律：先列营收结构、利润结构和未来驱动力；三者不一致时拆分；跨国对象用“主要市场 + 关键依赖”双标签。

## 二、建立产业地图

先画狭义主线，再叠加广义关联：

```text
原材料 → 核心部件/工艺 → 制造/集成 → 渠道/平台 → 最终用户 → 回收/再利用
```

每张地图至少包含：

1. 节点：3-8 个有独立经济结构的细分环节；
2. 关系：产品流、信息流、资金流和关键依赖；
3. 玩家：每个节点 2-3 个代表性参与者；
4. 利润：利润集中度及其变化方向。

对线性产业可用上中下游；对网状产业补三类节点：横向支援、平台、关键技术瓶颈。垂直一体化公司要跨节点标示，不能硬塞进单一环节。

必须分清：供应链是物料和物流的物理路径；企业价值链是单家公司内部创造价值的活动；产业链是多家企业之间的经济、技术和议价关系。

## 三、叠加动态状态层

产业地图说明行业结构，动态状态层说明结构中正在发生什么变化。系统认知和状态更新必须结合 [行业状态、叙事与利润传导](state-change-and-narrative.md)，用未来 6–24 个月经营时钟检查需求、有效供给、价格、库存、利润池、竞争、技术、政策地缘和资本开支。

动态分析不以新闻数量或股价涨跌代替产业变化。关键变化必须有明确基线，并继续推演到订单、销量、价格、产品结构、产能利用率、利润和现金流；同时说明传导时滞、供给响应和价值泄漏。再判断它只改变短中期路径，还是也改变长期需求、竞争与资本强度边界。

市场叙事单独记录：此前基线、最新说法、产业事实支持到哪一步、尚未验证的利润环节和证伪数据。当产业事实已经足以使某项现有经营叙事需要上调、下调或重构，但尚未经过明确市场预期基线和价格隐含分析时，可记为 `Narrative Gap Candidate`，作为 `narrative-valuation` 的研究入口；它不等同于正式预期差。卖方与媒体用于识别叙事和预测，不能单独证明经营事实；报告密度只代表关注度，不自动代表一致预期。

## 四、六问覆盖层

### Q1：体量、增长、周期与生命周期

回答行业有多大、增速来自哪里、增长是否持续、当前处于哪个时间位置。

同时区分宏观经济周期、行业周期、产能/库存周期，以及导入、成长、成熟、衰退四阶段生命周期。生命周期至少用渗透率、玩家数量与集中度、平均利润率走势、资本开支强度交叉判断；显式说明地理差异和口径。

资源与周期行业避免使用单年 PE 描述周期位置；关注价格、库存、产能利用率、资本开支、边际成本和新增供给周期。

### Q2：产业地图、价值链与利润分布

识别价值在哪个节点创造、利润在哪个节点留下、利润是否正在迁移。利润集中通常来自六类机制：技术/专利、网络效应、品牌与锁定、规模与学习曲线、监管特许或独占权、资源禀赋。

“技术含量高”不等于“利润集中”。同时检查替代品、互补者、平台节点和关键瓶颈。

### Q3：商业模式、竞争、护城河与资本回报

先识别主要商业模式：生产制造、平台、IP 授权、数据/算法、资源租金、专业服务、订阅/经常性收入、复合模式。

用五力加现代补充解释行业结构：供应商、客户、新进入者、替代品、现有竞争者，加互补者、数据/网络效应、政府/监管；把并购整合作为改变玩家结构的动态变量单列追踪。

行业层的护城河分析只输出利润留存机制和赢家特征。护城河要通过三项检验：能否持续、能否产生 ROIC 高于资本成本、能否找到财务或经营证据。不要在这里越界形成个股 Alpha。

### Q4：技术 S 曲线与颠覆风险

列出当前主流路线、候选路线、性能/成本关键指标、商业化阶段和切换条件。判断技术处于早期、加速还是饱和段，是否出现新一轮 S 曲线接力。

严格区分持续性创新与从低端或新市场切入的颠覆性创新。高端新产品造成行业震动，不自动等于经典意义的“颠覆”。同时分析材料替代、流程替代、效率提升和需求消失风险。

### Q5：监管、地缘、国际比较与中国位置

监管从七个维度扫描：准入、政府定价或集中采购、反垄断、环境/碳/ESG、数据与网络安全、极端干预、产业政策与国家力量。高度监管行业中，监管就是基本面。

国际比较必须同单位、同时间、同口径并拆到细分环节；优先比较产业链位置、各环节份额、技术指标、客户结构和资本回报，避免笼统比较整体产值。

国产替代按五阶段判断：完全进口依赖、国产可用但低端少量采用、中端突破、中高端突破仅尖端依赖、全球领先。证据至少覆盖进口替代率、真实客户采用、国际份额、专利/技术指标。替代成功不等于投资回报，价格战可能把价值转移给客户。

### Q6：估值语言、市场叙事与数字假设

行业层只判断适合的估值语言和叙事约束：成熟稳定业务偏 DCF/PE，金融和强周期偏 PB，早期成长偏 PS/用户数，重资产周期偏 EV/EBITDA、重置成本或储量 NPV，复合模式偏 SOTP。至少用两种方法交叉，且与商业模式、生命周期和地理口径匹配。

把叙事转换为体量、份额、价格、利润率、资本投入、现金流和兑现时间等数字；再用 3P 检验：物理/法律/技术上是否 Possible，商业逻辑上是否 Plausible，在基率和证据下是否 Probable。行业认知报告不计算个股公允价值。

## 五、六问不是孤立清单

至少检查以下约束：

- Q4 技术路线变化会重画 Q2 地图并改变 Q3 赢家特征；
- Q5 监管和地缘会改变准入、价格、产能和利润分布；
- Q1 周期位置会让 Q3 的 ROIC 和利润率暂时失真；
- Q3 竞争与资本回报会反向约束 Q1 的可持续增长；
- Q6 的叙事数字必须同时经 Q1-Q5 的事实校验；
- 国产替代结论必须落回 Q2 的具体节点和 Q3 的利润留存机制。
- 动态状态层负责解释最近的变化，六问负责判断变化发生在什么结构中；两者不得互相替代。
- 短期供需和库存变化先影响经营路径，只有能持续改变渗透率、份额、单位经济或资本强度时，才上调或下调终局边界。

## 六、研究与持续追踪

信息源分为财经媒体、卖方研究、公司公告/业绩会、行业协会、学术论文和一手数据。不存在统一的“最高级来源”；应按问题选择并交叉验证，特别警惕媒体戏剧化、卖方乐观偏差、管理层陈述偏差和学术时滞。

建立三类长期资产：行业字典；覆盖中期状态与长期终局的分频率 dashboard；主动寻找反证的“杀死叙事”清单。每次更新保留上次基线，只追加新证据和判断变化，不用新结果改写旧预期。

行业地图在技术切换、重大监管、并购整合或利润池迁移后重画；至少每年复核一次。
