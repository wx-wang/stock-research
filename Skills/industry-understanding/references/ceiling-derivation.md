# 行业天花板推导方法

把 Industry Terminal Packet 中"从当前到终局的需求/渗透/替代/单价路径"从字段要求变成可执行的推导。本方法是 Q1（生命周期）与 Q4（技术路线）的数值延伸：Q1 判断"现在在 S 曲线哪一段"，本方法回答"曲线顶在哪、终局数值取多少"。

## 一、饱和点（终局需求）估计：四种母方法

| 方法 | 逻辑 | 适用条件 | 所需数据 | 常见错误 |
|---|---|---|---|---|
| 1. 渗透率对标法 | 找已饱和的相似市场/国家，以其渗透率终值封顶 | 存在结构相似的对标对象 | 对标市场渗透率史、结构差异清单 | 对标对象结构性不同（人口、政策、基建）；只找支持性对标 |
| 2. S 曲线拟合 | 用历史渗透率/销量拟合逻辑斯蒂曲线，取渐近线 | 渗透数据 ≥5 年、处于成长段 | 年度渗透率或销量序列 | 数据太短外推敏感；把政策脉冲/一次性事件拟合进趋势 |
| 3. 人均/单位保有量法 | 人均或单位 GDP 消耗量对标发达经济体饱和值 | 耐用消费品、基础设施、资源消耗 | 人均保有量国际序列 | 忽视制度、地理、技术代际差异（如跳过固话） |
| 4. 约束封顶法 | 物理/资源/制度/上游产能封顶 | 任一硬约束可辨认 | 资源储量、牌照配额、电网接入、上游在位者产能 | 把软约束当硬约束；忽略约束本身会随价格/技术放松 |

纪律：

- **至少两法交叉**，输出为区间而非点值；两法结果背离时写明原因并保留分歧。
- 每种方法注明依据数据的时间与口径（沿用 Q5 的同口径纪律）。
- 终局不是物理最大值：约束封顶法给的是"产业可能边界"，直接当终局会系统性高估。

## 二、漏斗分解：从总需求到公司可及市场

终局需求不等于公司市场。按层分解，**每层独立举证**：

```text
L1 总需求（最小计价单位口径）         ← 第一节推导
L2 技术路线分流（Q4：路线 × 替代路线）  ← 每条路线的终局渗透率
L3 区域/环节/客户结构分流              ← 公司实际覆盖的范围
L4 公司可及市场（= L1×L2×L3）
公司份额（交给下游 narrative-valuation，行业层只给"份额可行区间的产业约束"）
```

- 每层记录：口径、当前值、终局值、推导方法（四法之一或定性依据）、可证伪变量。
- **防连乘纪律**：任一层没有独立依据就标`需要复核`；不得跳层（用 L1 直接当 L4）；层与层之间若有相关性（如路线 A 份额高时 L3 自动扩大），必须显式说明而非当作独立乘数。
- 无统一分母时照常写`市占率未知`，用 L4 的替代口径（产能、订单、项目漏斗）并标注代理性质。

## 三、供给交叉验证：用供给侧数据校验需求侧推导

需求推导完成后，必须用供给侧数据做一致性检验：

1. **在位者订单与在手积压**：上游/同业公司的订单簿、排产周期是需求的实物证据（如 OEM 燃机在手 GW、发动机厂在手台数）；
2. **上游关键部件在位者产能**：关键部件（机头、芯片、核心设备）在位者的产能与扩产计划 = 赛道年装机的物理上限，同时是下游集成商的配额约束；
3. **竞争者扩产公告**：同路线竞争者的资本开支与产能规划 = 终局份额的约束，也是"窗口期 vs 持续需求"的判别证据；
4. **一致性检验**：需求侧终局装机 > 所有在位者产能之和 → 需求推导或产能数据有误，必须复核；订单簿年化交付能力 ≫ 公司自述产能 → 产能数据过时或订单交付期被低估，标记矛盾而非择一相信。

## 四、三态边界（行业层输出前两条）

下沉自 `narrative-valuation` 的边界区分，行业层只输出前两条：

- **产业可能边界**：物理/技术/制度全部打开时的需求上限。只用于压力测试，不进入估值。
- **证据支持边界**：竞争、资本、商业现实下可演绎支持的终局。Pass A 独立终局只能锚在这里。
- **价格隐含边界**：由下游估值反推，行业报告不计算；但若下游要求，可提供"不同终局需求对应的行业含义"以供对照。

## 五、天花板仪表盘

终局推导的每个关键变量进入追踪仪表盘（并入输出模板第七节），字段：

```text
变量 / 当前值 / 终局假设值 / 推导方法 / 验证频率 / 数据来源 / 阈值方向（偏离多少触发重估）
```

典型的天花板跟踪变量：渗透率、终局占比类变量（如某技术路线份额）、上游在位者订单/产能、替代路线的放量速度、约束条件本身（政策、牌照、资源）的变化。

## 六、与 Industry Terminal Packet 的字段对应

| Packet 字段 | 本方法来源 |
|---|---|
| 当前行业规模及口径 | Industry Scope Card + L1 |
| 从当前到终局的需求/渗透/替代/单价路径 | 第一节四法 + 第二节 L2/L3 |
| 终局后长期行业增速 | 终局稳态的更新/替代需求推导（S 曲线饱和段） |
| 公司份额可行区间的产业约束 | 第二节 L4 + 第三节第 3 条 |
| 单位经济与资本强度 | Q2 利润分布 + 供给交叉验证中的产能经济性 |
| 终局持续性 | 稳态更新需求 + 替代路线切换条件（Q4） |
| 证伪条件/关键未知/下一验证数据 | 第五节仪表盘 |
| 产业可能/证据支持边界 | 第四节 |
