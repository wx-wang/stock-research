# 行业认知报告模板

写作遵循[研究报告写作规范](../../../研究规则/研究报告写作规范.md)。以下是分析内容的覆盖要求，正文按读者问题组织，不直接照抄内部名称与字段。


模板服务于可读性，不要求机械填满每一栏。六问、状态卡和终局包是内部覆盖框架，不是默认正文目录。普通行业报告优先压缩为：核心判断、行业怎样赚钱、3—5个关键证据与变化、未来6—24个月传导、长期终局与约束、最大不确定性、下一验证指标、数据来源。只有用户明确要求系统认知或方法审计时，才展开完整结构。

## 写作标准

- 标题直接回答读者问题，避免连续使用只有研究人员才懂的框架名。
- 每节先用一两句话给判断，再解释原因和证据。不要先堆一张大表，让读者自己寻找结论。
- 保留必要术语，但首次出现时解释它在本行业中的实际含义。少用缩写；必须使用时同时给中文名称。
- 一段一个主要判断。长句拆开，因果链写清楚，不把多个不相关观点塞进同一句。
- 数字紧邻日期、地区、单位、口径和来源。表格只承载比较关系，表前或表后说明它意味着什么。
- 内部记录对事实与假设分类；正文自然说明“公司已披露”“管理层预计”“本报告假设”，不逐项贴内部标签。
- 语气专业、自然、克制。避免术语堆砌、营销式标题、过多比喻、口语梗和模板化套话。

## 1. 先说结论：几分钟理解这个行业

用短段落回答：

- 这个行业到底提供什么产品或服务，解决谁的什么问题？
- 谁是使用者，谁做采购决定，谁最终付钱？
- 最重要的收入来源和利润环节在哪里？
- 当前行业处于什么状态？
- 最近最重要的 1–3 个变化是什么？
- 最大的不确定性是什么？

这里不能只写“空间大、景气高、壁垒强”；必须把判断落到可观察变量。

- 直接与间接替代品：

- 数据截止日期和主要口径：

## 3. 生意怎样运转：产品、客户与资金

先用一段话说明商业关系，再用文本链或小表展示产业地图。至少包括最终客户、采购决策者、渠道/平台、制造或服务节点、核心部件/资源、横向支援和关键瓶颈。

```text
原料/技术 → 核心部件或能力 → 制造/集成 → 渠道/平台 → 采购方 → 最终使用者
```

说明产品流、资金流和关键依赖。代表玩家用于帮助定位，不形成股票推荐。

## 4. 钱在哪里赚：价值链与利润分布

先回答利润主要留在哪些环节、为什么能留下，再给节点比较：

| 环节 | 提供的价值 | 客户为什么付钱 | 收入模式 | 成本与资本投入 | 议价权 | 利润池及变化 |
|---|---|---|---|---|---|---|

区分“创造价值”和“留住利润”。说明价格战、客户议价、上游涨价、扩产或技术替代会怎样重新分配利润。

## 5. 现在是什么状态：未来 6–24 个月

用一段话给出总体判断：改善、恶化或基本不变；相对什么基线；最关键的依据是什么。再呈现行业状态表：

| 变量 | 当前状态与日期 | 比较基线 | 方向/加速度 | 主要原因 | 持续性与反转条件 | 影响节点 |
|---|---|---|---|---|---|---|
| 需求与订单 | | | | | | |
| 供给、产能与利用率 | | | | | | |
| 价格与产品结构 | | | | | | |
| 库存 | | | | | | |
| 成本与利润池 | | | | | | |
| 竞争与份额 | | | | | | |
| 技术、政策与地缘 | | | | | | |
| 资本开支 | | | | | | |

不重要的行可以省略；没有明显变化时直接说明。

## 6. 最近发生了什么：变化、叙事与事实

先指出真正改变判断的 1–3 件事，并区分周期转折、景气加减速、产业结构变化或利润分配变化。

| 市场观点或预测 | 原有判断 | 新证据 | 是否需要修正判断及原因 | 尚待确认的问题 |
|---|---|---|---|---|

说明哪些只是市场关注度上升，哪些已经有订单、价格、产能、客户采用或财务数据支持。不要把卖方集中讨论直接称为一致预期，也不要把叙事变化写成经营事实。叙事差异候选（Narrative Gap Candidate）不必逐行填写，只写经营假设层面的修正方向（例如“全面复苏可能应修正为结构性复苏”），不写目标价、“被低估”或“市场尚未定价”之类的估值结论；正式预期差由估值层确认。

## 7. 变化怎样进入利润和现金流

对真正影响判断的变化，说明它如何逐步影响收入、利润和现金流：

```text
驱动力
→ 首个可观测领先信号
→ 终端需求或有效供给变化
→ 订单/销量
→ 价格、产品结构、产能利用率
→ 单位毛利和利润池
→ 典型企业收入与经营利润
→ 营运资本、资本开支和股东现金流
```

写明驱动力属于外生需求、供给约束、技术、政策还是竞争变化；领先信号为何领先、通常领先多久、可能出现哪些假信号。再写明每一段的证据、预计时滞、供给响应、竞争分流和兑现成本。行业层说明典型机制与公司可捕获边界，不代替公司财报分析。

## 8. 长期增长空间有多大，受到哪些限制

说明终端需求单位、渗透率和替代路径、终局后增长、供给与容量约束、价值链利润分布、竞争格局、技术监管风险和资本强度。

明确区分：

- 短期变化只改变到达终局的路径；
- 短期变化同时改变终局边界；
- 现有证据不足，暂时不能判断。

需要支持估值时，正文说明理论上可能达到的规模与现有证据支持的规模有何差别。供估值复用的完整行业资料（Industry Terminal Packet）另存内部研究记录，不整包附在正文。

| 跟踪指标及来源 | 当前值与比较日期 | 下一次披露时间 | 什么变化需要调整判断 |

## 11. 最大不确定性与下一步

- 最大风险或不确定性：
- 它为什么会改变当前判断：
- 最有价值的下一步验证：

普通行业报告不展示内部证据账本、Claim ID、Lineage ID或逐条置信度表。研究过程仍需完成主张分类、来源追溯和独立性检查，但只把影响判断的证据限制用自然语言写进相关章节。

报告最后增加“数据与资料来源”，按使用性质分组列出：

- 官方、监管与行业数据库；
- 公司公告、财报与经营数据；
- 券商研报；
- 知识星球、IMA或其他市场叙事资料。

每项至少写资料名称、机构/作者、发布日期、链接或本地文件及主要用途。研报预测和社群观点标为预测、分析或叙事，不与已发生事实混写。只有用户明确要求证据审计时，才另附主张级证据账本。
