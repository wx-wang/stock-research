# 行业状态、叙事与利润传导

本参考用于系统认知、状态更新，以及用户询问行业供需、景气、边际变化或市场叙事时。它补充六问框架，解决“行业最近发生了什么、能否持续、会不会进入利润”的问题，不形成股票买卖或交易时点结论。

## 一、使用两只时钟

行业研究同时保留两条时间线：

- **经营时钟（未来 6–24 个月）**：需求、订单、供给、价格、库存、产能利用率、利润池和资本开支怎样变化。
- **产业时钟（走向成熟或终局）**：渗透率、替代率、长期需求、竞争格局、单位经济和资本强度最终可能稳定在哪里。

短期改善不自动提高长期终局。补库存、一次性政策刺激或短暂供给事故，可能只改变一两个季度；技术路线确认、客户采用、永久性产能退出或成本曲线变化，才可能重画长期边界。每项关键变化都要回答：它只改变路径，还是也改变终点？

## 二、Industry State Card

先找状态，再找变化。对相关变量记录“水平、方向、加速度、持续性”，不要只写好转或恶化。

| 变量 | 需要回答的问题 | 常见指标 |
|---|---|---|
| 需求与订单 | 真实使用需求、备货还是政策拉动？订单能否取消或延后？ | 订单、出货、装机、销量、渗透率、客户资本开支 |
| 供给与产能 | 名义产能是否真正可用？新增供给何时投放？ | 有效产能、利用率、投产/爬坡、停产退出、交付周期 |
| 价格与产品结构 | 价格变化来自短缺、成本传导还是高端产品占比？ | ASP、现货/长协价差、折扣、产品组合、单位价值量 |
| 库存 | 库存在原料、生产商、渠道还是客户手中？ | 库存量、库存天数、渠道周转、补库/去库速度 |
| 成本与利润池 | 收入增长最终由谁留成利润？ | 原料、良率、单位成本、加工费、毛利率、现金成本 |
| 竞争与份额 | 改善会不会很快引来扩产和价格战？ | 市占率、集中度、新进入者、客户集中度、招投标价格 |
| 技术与产品 | 新路线到了实验、验证还是批量采用？ | 性能/成本、良率、认证、客户采用、替代方案进度 |
| 政策与地缘 | 影响的是需求、供给、价格、成本还是准入？ | 补贴、集采、配额、关税、出口管制、环保和安全要求 |
| 资本开支 | 谁在扩产，扩什么，何时变成有效供给？ | 资本开支、在建工程、设备交期、融资、维持性投入 |

每个重要变量使用统一记录：

```text
变量与口径：
当前值 / 日期：
比较基线：上期、去年同期、原计划或事件前预测
水平 / 方向 / 加速度：
主要原因：
预计持续时间与反转条件：
影响的产业链节点：
证据与数据缺口：
```

如果数据只支持方向，不虚构幅度；如果没有合适基线，不使用“加速、见底、反转、超预期”。

每个决定性状态主张还要记录它的证据角色、主张级置信度和根来源。公司公告、数据库复刻及媒体转述若来自同一披露，只算一条证据链。

## 三、识别真正重要的变化

把变化归入下列一种或多种类型，并解释依据：

1. **周期转折**：从去库存到补库存、价格止跌、产能退出或利用率回升。
2. **景气加速或减速**：原有方向没有改变，但订单、渗透率或价格斜率发生明显变化。
3. **产业结构变化**：技术路线、产品形态、客户采购方式、监管或地缘条件重画产业关系。
4. **利润分配变化**：总需求变化不大，但短缺、议价权、成本或竞争使利润向某个节点迁移。

报告只突出足以改变产业判断的 1–3 个变量。新闻很多但关键变量未变时，应明确写“信息增加，但行业状态没有实质变化”。

### 代表公司变化不能自动升级为行业变化

单家公司订单、收入、价格、项目或产能只直接证明该公司的变化。用于行业状态前，必须竞争检验：

1. **行业 Beta：** 多家可比公司、客户、供应商或行业统计是否同向；
2. **公司 Alpha：** 是否来自份额提升、客户迁移、执行或产品优势；
3. **细分结构：** 是否只有特定产品、地区、客户或技术路线改善；
4. **口径因素：** 是否来自并表、处置、汇率、低基数或收入确认变化。

只有行业统计或至少两条真正独立、同口径的跨主体证据支持时，才明显提高行业判断置信度。多家公司引用同一行业调查，不构成多条独立证据；无法区分时写“公司样本显示变化，行业外推仍待验证”。

## 四、行业变化如何影响利润与现金流

任何“行业变好”都要继续推演：

```text
驱动力
→ 首个可观测领先信号
→ 需求或有效供给变化
→ 销量 / 价格 / 产品结构 / 产能利用率
→ 单位毛利和利润池迁移
→ 典型企业收入与经营利润
→ 营运资本、资本开支和股东现金流
```

领先信号必须解释为什么领先、通常领先多久、在哪些情况下会失真。无法建立领先关系时，应称为同步指标或结果指标，不能为了完整链条强行贴上“领先”标签。

逐段检查四个问题：

- **传导时滞**：价格和库存可能按周变化，订单按月或季度确认，收入、利润和现金流通常更晚。
- **价值泄漏**：降价、客户议价、上游涨价、渠道分成、竞争扩产、税费或监管会拿走多少新增价值。
- **兑现成本**：增长是否需要大量资本开支、营运资本、融资或稀释。
- **上市主体归属**：利润是在目标公司的上市主体、合资公司、少数股东项目，还是未上市供应商中实现。

行业层只给出典型传导机制和公司可捕获边界；具体公司的正常化利润与现金转化由财报分析确认。

## 五、Narrative Change Card

市场叙事不是行业事实，但它能说明研究参与者正在关注什么，以及未来哪些数据最可能改变预期。

| 叙事或预测 | 此前基线 | 最近变化 | 产业事实支持到哪一步 | 缺失的利润环节 | Narrative Gap Candidate | 下一确认数据 / 证伪数据 |
|---|---|---|---|---|---|---|

使用纪律：

- 卖方研报适合建立行业地图、发现数据入口和整理预测假设。订单、客户、份额、技术和利润事实尽量回到公告、监管、协会或结构化数据。
- 多家报告集中讨论同一主题只说明关注度提高。只有来源范围、统计时点和预测口径足够清楚时，才称为一致预期；否则写“常见卖方叙事”或“已检索报告中的主流表述”。
- 区分“叙事发生变化”和“事实发生变化”。叙事从长期空间转向订单兑现，不等于订单已经兑现。
- 没有事件前基线，不把事后结果描述为超预期。可以写“高于此前某项明确预测”，并给出预测来源和日期。
- 行业报告可以指出“现有叙事可能需要上调或下调哪些经营假设”，但不判断股票是否已经充分定价；价格隐含终局由 `narrative-valuation` 独立反推。

### Narrative Gap Candidate（叙事差异候选，待估值层确认）

当产业事实已经足以挑战现有叙事中的某个经营假设，但尚未具备明确市场预期基线和价格隐含分析时，可标记为 `Narrative Gap Candidate`。它不是正式预期差，不判断股票是否低估或高估。行业层只回答“哪个经营假设可能错了”；“这个错误有没有反映在价格里”由 `narrative-valuation` 回答。上表候选列不必逐行填写，只在经营证据形成一定支持的差异处填写。

每个候选至少说明：

- 现有叙事或经营假设是什么；
- 哪个产业事实正在挑战它；
- 可能需要上调或下调哪个经营变量；
- 当前证据支持到哪一步；
- 尚缺什么数据；
- 哪些数据应交给 `narrative-valuation` 继续确认。

只有在经营证据已经形成一定支持时才建立候选。单纯因为股价未上涨、卖方关注较少、公司估值较低或市场讨论较少，不构成 Narrative Gap Candidate。

## 六、持续性判断与跟踪

每项关键变化至少判断：

- 是一次性、季节性、补库存、周期性还是结构性；
- 支持它持续的机制是什么；
- 供给响应或替代方案需要多久；
- 哪个数据最先证明判断正确或错误；
- 它会改变 6–24 个月路径，还是同时改变长期终局。

跟踪频率服从数据频率：价格和高频库存可日/周更新；订单、利用率和行业产量通常月/季更新；利润率和资本开支通常季/半年更新；技术认证、政策和地缘事件按事件更新。不要为了周报形式重复没有新增信息的数据。

建议 dashboard 字段：

```text
变量 / 链上节点 / 基线值与日期 / 当前值与日期 / 方向与加速度 /
更新频率 / 下一数据点 / 触发阈值 / 影响的中期路径或终局假设 / 来源
```
